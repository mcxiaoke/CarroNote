# Changelog

## 3.0.0

- End-to-end encrypted notes with multi-device sync
- AES-256-GCM encryption with Argon2id key derivation
- Three sync backends: SafeServer, WebDAV, local filesystem
- Cross-platform: Windows, Android, iOS, macOS, Linux, Web
- 18 language translations
- Markdown editor with live preview
- Note versioning and history
- Biometric authentication (fingerprint / Face ID)
- Automatic encrypted backups
- Note tags, pinning, and lock
- Dark theme with customizable seed color
- CLI client for headless sync operations
