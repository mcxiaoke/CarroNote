# 变更记录 2026-08-17

## 登录页错误提示位置改为 label 行右侧 + 布局上移与键盘滚动修复（2026-08-17 13:20）

文件：`lib/views/authentication/login.dart`

**需求**：错误提示放在输入框下方会随有无错误改变输入框与按钮间距、且贴住输入框 outline，
布局不稳定；输入时登录按钮被软键盘遮挡。

**改动**：
- 删除 `_buildError()` 独立文案区，错误提示改渲染在密码输入框 `label` 行右侧（`label`
  用 `SizedBox(width: double.infinity)` 包 `Row(spaceBetween)`：左侧 "Passphrase"，右侧
  circleAlert 图标 + 错误文本，文本 `Flexible` + ellipsis 防溢出）。有/无错误不再改变
  输入框与按钮的垂直间距。
- 软键盘滚动修复：`_scrollController` 从外层 `CustomScrollView` 移到 `_buildLoginWorkflow`
  内部 `SingleChildScrollView`（外层 SliverFillRemaining 不可滚、maxScrollExtent 恒为 0，
  此前 `scrollToBottomIfOnScreenKeyboard` 实际无效，键盘弹出时按钮被遮挡）；外层
  CustomScrollView 不再绑定 controller。
- 整体上移：`_buildTopLogo` 顶部间距 24 → 8，输入框与提示区上移 16px。

**验证**：`flutter analyze lib/views/authentication/login.dart` 无 issue；
`test/auth_flow_test.dart` 3 用例全过。

## 登录页错误提示由全局 Toast 改为页内联文案（2026-08-17 12:50）

文件：`lib/views/authentication/login.dart`

**需求**：登录页提示（密码错误、剩余尝试次数、尝试超限锁定、远端网络不可达）不再使用
Toast；界面切换（登录成功进入 home）后提示必须立即消失，不得在 home 上方残留。

**问题根源**：`showErrorToast` 走 ShadSonner 全局浮层，其挂在 Navigator 之上（`app.dart`），
Toast 不随路由销毁；错误类 Toast 时长 6 秒，登录成功后 `pushReplacementNamed('/home')`
时旧 Toast 仍悬停在 home 上方。

**改动**：
- 新增状态 `String? _errorMessage`，及辅助方法 `_showError(msg)` / `_clearError()`，
  二者均带 `mounted` 守卫。
- 新增页内联错误文案 `_buildError()`：置于输入框下方（`_buildLoginWorkflow` Column 中
  `_inputField()` 之后），destructive 配色 + `LucideIcons.circleAlert` 小图标，无错误时
  返回 `SizedBox.shrink()` 保持布局稳定。提示 Widget 绑定登录页生命周期，路由切换即销毁。
- 4 处 `showErrorToast` 全部替换为 `_showError`：表单校验失败（Wrong passphrase!）、
  远端网络不可达、尝试次数超限锁定（Number of attempt exceeded）、密码错误剩余次数。
  锁定倒计时 `_buildTimeOut()`（本就为页内联）保持不变，与错误文案共存。
- 输入框新增 `onChanged: (_) => _clearError()`：用户重新输入时立即清除陈旧错误文案。
- 登录页布局修复：表单区域改由 `Expanded` 包裹（`_buildLoginWorkflow` 内部本就带
  `SingleChildScrollView`），原先 `Column + Spacer` 固定高度布局在错误提示动态增高表单时，
  窄视口（如测试 800x552）会 RenderFlex 溢出 17px；改为 Expanded 后表单可滚动兜底。
- 保留 `snack_message.dart` import：`_performLocalDataReset`（重置数据流程反馈）仍用
  `showSnackBarMessage` / `showErrorToast`，不在本次改动范围。

**验证**：`dart format` 通过；`flutter analyze lib/views/authentication/login.dart`
无 issue；`test/auth_flow_test.dart` 3 用例全过。
