# 变更摘要 2026-08-17

## 主题换色：灰度色被渲染成彩色的修复（最终：方案 A+C，最简单）

> 更新 18:04：方案 B（seed 亮度明暗 + ShadNeutralColorScheme）实测观感未提升、且自定义
> ShadCN 代码较多，已回退。最终采用最简单方案 A+C：两端共用 buildSeedColorScheme，中性
> seed 走 monochrome（明暗跟随全局暗色开关）。

根因：`ColorScheme.fromSeed` 默认 `tonalSpot` 只取 seed 的 HCT 色相、把 primary 色度
硬编码为 36，中性灰度色会被赋一个无意义伪色相并放大成彩色（米白/瓷白/墨黑偏青、纯黑偏粉紫）。
详见 `docs/THEME_COLOR_INVESTIGATION.md`。

- 新增 `lib/models/seed_scheme.dart`
  - `isNeutralSeed(Color)`：RGB 三通道最大差值 ≤ 26 判定为中性灰度色（全色库扫描恰好命中
    通用组 6 个灰度尾色 + 深邃组黑曜石，不误伤米色/奶油棕/灰豆绿等浅彩色）。
  - `buildSeedColorScheme(Color, Brightness)`：中性灰度 seed 用
    `DynamicSchemeVariant.monochrome`（色度恒 0）+ 传入 brightness；彩色 seed 保持
    默认 `DynamicSchemeVariant.tonalSpot`。
  - 顶部注释保留方案 B 备选思路（seed 亮度明暗 / ShadNeutralColorScheme），备忘用。
- `lib/models/app_theme.dart`：`AppThemes.build` 改用 `buildSeedColorScheme` 生成
  M3 ColorScheme（原 `ColorScheme.fromSeed(seedColor: seed, brightness)`）。中性=monochrome。
- `lib/models/shad_theme.dart`：`ShadThemes.build` 同样调用 `buildSeedColorScheme`
  （ShadCN 品牌色来源，保证 Material 与 ShadCN 两端同逻辑、同步换肤），再映射到
  `ShadSlateColorScheme`（无自定义中性色板）。
- 新增 `test/theme_neutral_verify_test.dart`：中性识别 / monochrome 输出为灰度 /
  彩色不误判为中性，全部通过。

验证：`flutter analyze` 三个 model 文件 + 测试无错误/警告；`flutter test test/theme_neutral_verify_test.dart`
全部通过。6 个灰度尾色修复后均为真正中性主题（不再彩色），明暗同彩色 seed 一样由全局暗色开关控制；
彩色与浅彩色（米色/灰豆绿等）行为不变。
