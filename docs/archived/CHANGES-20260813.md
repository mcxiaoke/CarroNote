## 备份导入 uuid 幂等去重修复（2026-08-13 19:45 GMT+8）

### 问题
「导出备份 → 立即导入同一份备份」报 `UNIQUE constraint failed: safe_notes.uuid`
并整体回滚。根因：App 导入路径 `lib/models/file_handler.dart:insertNotes` 直接调
`storeNotesInTransaction` 裸 INSERT，同 uuid 撞唯一约束；而 CLI `import`
（`bin/cli_commands.dart`）早已是「按 uuid 幂等跳过」，App 侧一直没落地。

### 改动

- **`packages/core/lib/src/db/database_handler.dart`** `storeNotesInTransaction`：
  新增 uuid 幂等去重——先查候选 uuid 是否已存在于库（含墓碑，墓碑同样占用
  唯一键），已存在的跳过，仅新增本地没有的；返回**实际插入**数量（跳过不计）。
  去重查询按 400 条 chunk 折叠 SQL `IN` 子句，避免超大导入触碰
  SQLITE_MAX_VARIABLE_NUMBER 上限。与 CLI `import` 语义一致，CLAUDE.md 协议
  兼容性无影响（仅 DB 写路径行为变更）。
- **`lib/models/file_handler.dart`**：`insertNotes` 改为返回被跳过的条数；
  `selectFileAndImport` 在有跳过时返回带提示的文案
  `{imported} notes imported, {skipped} skipped (already exist).`
  （已新增 en-US / zh-CN 翻译键，其它语言由自动翻译补全，本次只动中英）。
- **新增 `packages/core/test/sync/database_import_test.dart`**（4 项）：首次导入全量
  写入 / 重复导入同一备份全部跳过不抛冲突 / 混合场景已存在跳过其余新增且不覆盖 /
  墓碑同样占用 uuid 跳过。验证方法见 CLAUDE.md §2：`dart test packages/core/test/sync/database_import_test.dart`。

## 暗色模式对比度修复：Shad 侧改走 M3 自适应色板（2026-08-13 11:05 GMT+8）

### 问题
暗黑模式下（如默认 0-0 深海蓝）几乎所有按钮「深色底 + 黑色字」看不清，
笔记颜色页选中项文字同样看不清。

### 根因
`ShadThemes.build` 的 `copyWith` 只覆盖了 `primary: seed`，未同步
`primaryForeground`。而 `ShadSlateColorScheme.dark()` 的 primaryForeground
默认是深色（#0f172a）→ 深 seed 底色 + 深文字 = 不可读。浅色模式恰好默认
primaryForeground 是白字，所以未暴露。**这是 Shad 对接层破坏了主题色自动对比
机制**，而非业务代码没用主题色 —— FCS（Material）侧一直正常（M3 自动推导
onPrimary，暗色下 primary 自动提亮、文字自动变深，对比度 7.75:1）。

### 改动（lib/models/shad_theme.dart 重写）
- 品牌相关色一律改用 M3 `ColorScheme.fromSeed(seedColor: seed, brightness:)`
  生成的色板映射，不再直接塞裸 seed：
  - `primary/primaryForeground` ← m3.primary / m3.onPrimary（核心修复）
  - `secondary/secondaryForeground` ← m3.secondary / m3.onSecondary
  - `accent/accentForeground` ← m3.primaryContainer / onPrimaryContainer
  - `destructive/destructiveForeground` ← m3.error / m3.onError
  - `ring` ← m3.primary；`selection` ← primary 20% 透明度
- 中性基底（background/foreground/card/border 等）仍沿用 Slate，页面观感稳定。

### 效果（实测对比度）
| 模式 | primary | 文字 | 对比度 |
|---|---|---|---|
| 浅色 | #3E5F90（深蓝） | 白 | ~7:1 ✓ |
| 暗色 | #A7C8FF（亮蓝） | #04305F（深蓝） | 7.75:1 ✓ |

暗色模式按钮变为「亮底深字」——这是 M3 标准暗色行为（primary 自动提亮保证
可读），任何 seed（含极深色）都自动自适应，无需手调任何颜色。
笔记颜色页/主题色页选中项文字用 colorScheme.primary，随修复自动变亮可读。

  13 用例全部通过。
