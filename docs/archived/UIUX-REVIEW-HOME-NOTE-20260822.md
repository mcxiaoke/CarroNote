# SafeNotes 首页 & 笔记页 UI/UX 易用性审查报告

- **日期**：2026-08-22
- **范围**：`lib/views/home.dart`（首页）、`lib/views/add_edit_note.dart`（笔记编辑/详情页）、`lib/widgets/note_card_body.dart`、`note_actions_sheet.dart`、`search_widget.dart`、`home_navigation_rail.dart`
- **对比基准**：Google Keep、Apple Notes（通用笔记赛道）；Standard Notes、Joplin（端到端加密笔记赛道，与本项目定位最贴近）；Notion / Obsidian（进阶参考）

---

## 一、审查结论速览

SafeNotes 在**加密模型、自动保存、版本历史、置顶/标签筛选、暗色与配色、响应式侧栏**上已经做得相当完整，代码质量与边界处理（防抖、键盘避让、隐私日志脱敏）都可圈可点。

但相对业界主流 App，首页与笔记页在 **"批量操作 / 快捷操作 / 组织层级 / 富文本入口 / 分享导出"** 五类体验上有明显短板。下面按页面列出可改善点与功能缺失，并标注优先级。

> 优先级：P0 = 高影响 + 低成本，建议近期做；P1 = 中高价值；P2 = 进阶/长尾。

---

## 二、首页（HomePage）

### A. 易用性可改善

1. **AppBar 无标题**（P1）— `home.dart:369` 的 `title:` 被注释掉，移动端进入首页后顶部没有"笔记"字样，也没有笔记总数，用户缺乏位置感与规模感。建议显示 `Notes` + 计数（如 `128`）。
2. **过滤指示不可内联清除**（P0）— `_filterIndicator()`（`home.dart:1042`）是只读文本，清除必须回侧栏点"笔记"。对比 Gmail/Keep 的过滤 chip 带 `×`，建议改成可点关闭的 chip，一键回全部。
3. **排序/显示菜单是开关大杂烩**（P1）— `_buildSortMenu`（`home.dart:564`）把"新→旧 / 按修改日期 / 相对时间 / 紧凑 / 配色 / 仅星标"混在一个 popover 里，既是显示偏好又是过滤，且**缺"按标题 A-Z""按创建时间倒序"等常用排序**。建议拆成：排序组 + 显示组 + 过滤（仅星标/标签）独立入口。
4. **无多选 / 批量操作**（P0，最大易用性缺口）— 首页 `OpenContainer` 单点即进编辑（`home.dart:830`），没有任何长按选中态。Google Keep / Apple Notes / Joplin 都支持长按进入多选 → 批量删除/星标/加标签。SafeNotes 完全缺失。
5. **卡片无快捷操作**（P0）— 星标/删除/锁定必须打开笔记 → 更多菜单（3 次点击）。桌面无 hover 快捷按钮，移动无滑动手势（swipe-to-delete/archive）。建议桌面 hover 显示星标/删除，移动加滑动。
6. **删除无撤销提示**（P0）— 删除后进回收站（`deleted_notes.dart`），但无 Gmail/Keep 式"已删除 · 撤销"snackbar，用户易误以为永久丢失。建议加 5s 撤销。
7. **搜索能力弱**（P1）— `_applyViewFilter`（`home.dart:995`）仅对标题+正文做小写子串匹配，**不支持按标签搜、无命中高亮、无结果计数展示**（计数只在日志里）。建议加标签搜索 + 结果数 + 关键词高亮。

### B. 功能缺失

- **文件夹 / 笔记本（层级组织）**：当前只有"标签 + 星标"扁平过滤，无 Apple Notes/Joplin 的文件夹树。笔记多于百条后定位困难。（P1）
- **多选批量**：删除/星标/加标签/移动，见上。（P0）
- **滑动手势**：删/归档/星标快速操作。（P0）
- **每笔记手动配色**：当前 `NotesColor.getNoteColor(notIndex: index)` 按序号**自动**取色，仅有全局"Notes Color"开关（`home.dart:647`）。Google Keep 允许用户手动选色，是卡片笔记的核心个性。（P1）
- **桌面键盘快捷键**：`⌘N` 新建、`⌘F` 聚焦搜索、方向键 + 回车打开、多选 `⌘A`。Notion/Obsidian/Joplin 桌面端标配，本项目无任何 shortcut。（P1）
- **笔记统计概览**：总数 / 本周新增 / 标签分布，空状态与首页都无引导。（P2）
- **从模板新建**：高频场景（会议记录、日记）一键套模板。（P2）

## 三、笔记页（AddEditNotePage）

### A. 易用性可改善

1. **无格式化工具栏**（P0，最大痛点）— 编辑态是纯文本框 + Markdown 语法（`add_edit_note.dart:258` `NoteFormWidget`），没有 **B / I / 标题 / 列表 / 引用 / 代码** 按钮。对非技术用户门槛高；Standard Notes、Joplin 即便主打 Markdown 也都提供工具栏。建议加一条 Markdown 格式工具条（插入语法即可）。
2. **无保存状态指示**（P1）— 纯自动保存（`_performAutoSave`，`add_edit_note.dart:209`），AppBar 无"已保存 / 保存中…"提示，用户缺乏安全感。建议加角落 `Saved` / `Saving…` 微指示。
3. **"锁定"语义误导**（P1）— `_toggleLock`（`add_edit_note.dart:392`）的"锁定"= 只读预览，**不二次验证身份**（Apple Notes 的锁定需设备密码/FaceID 才能打开）。标签易让用户误以为"加密保护"。建议改名"只读"或在锁定后进入需重新验证，并补充文案说明。
4. **操作入口过深**（P0）— 复制/星标/锁定/标签/历史/删除全部塞进"更多"（`_moreButton`，`add_edit_note.dart:309`），高频的星标、删除要 3 击。建议把星标、删除提升为 AppBar 一级按钮（删除用图标）。
5. **无字数/字符统计**（P2）— 编辑器底部无计数。
6. **无 MD 实时预览分屏**（P2）— 当前是"编辑 ↔ 预览"整页切换，缺"左编右览"分屏（尤其桌面宽屏浪费）。

### B. 功能缺失

- **富文本 / Markdown 工具栏**：见上。（P0）
- **附件 / 图片**：隐私设计在预览中禁用图片加载（`add_edit_note.dart:514` `imageBuilder` 返回空），属有意限制；但应**明确告知用户"不支持图片"**，并考虑像 Standard Notes / Joplin 那样提供端到端加密的**文件附件**。（P1）
- **清单 / 待办**：Google Keep 的灵魂功能，本项目无 checklist 类型笔记。（P1）
- **分享 / 导出单条笔记**：仅"复制到剪贴板"（`_copyAll`，`add_edit_note.dart:360`）。缺系统分享面板、导出 `.md`/`.txt`、打印。Joplin/Standard Notes 都支持导出。（P1）
- **Duplicate note（复制笔记）**：常见高频操作，缺失。（P1）
- **笔记间链接 / 双链 + 反向链接**：Obsidian 式 `[[ ]]` 关联，本项目无。（P2）
- **提醒 / 闹钟**：Keep/Apple Notes 提醒，加密笔记非必需但属差异化。（P2）
- **表格**：需确认 `flutter_markdown_plus` 是否渲染表格；若不支持则 Markdown 表格缺失。（P2）

## 四、跨页面 / 全局

- **删除撤销 toast 全局缺失**（P0，见首页第 6 点）。
- **桌面键盘快捷键全局缺失**（P1，见首页第 5 点）。
- **无障碍语义标签**：卡片已有 `Key` 但缺 `Semantics(label:)`，`build` 级 screen reader 体验可补。
- **设置发现性**：Markdown 开关、配色、相对时间等散落设置页，新用户不知在哪开；建议在首页排序菜单加"更多显示设置"直达。
- **i18n / RTL**：已知仅 `zh-CN` / `en-US`，且 GUI 不支持 RTL 布局（既定限制，仅记录）。

## 六、落地优先级建议

**P0（近期，成本低、体验提升大）**
1. 首页多选 + 批量删除/星标/加标签
2. 首页卡片快捷操作（桌面 hover / 移动滑动）+ 删除撤销 toast
3. 过滤 chip 可内联清除（带 `×`）
4. 笔记页格式工具栏（Markdown 语法插入）
5. 笔记页星标/删除提升为 AppBar 一级按钮
6. 保存状态微指示（Saved / Saving…）

**P1（核心价值）**
- 每笔记手动配色、文件夹/笔记本、桌面键盘快捷键
- 清单 / 待办、分享与导出（.md/.txt/系统分享/打印）、Duplicate note
- 搜索增强（标签搜索 + 结果数 + 高亮）、排序补全（A-Z / 创建时间）
- 附件（端到端加密文件）、"锁定"语义校正或二次验证
- AppBar 标题 + 笔记计数

**P2（进阶 / 长尾）**
- 模板新建、笔记间双链 + 反链、提醒闹钟、字数统计、MD 分屏预览、统计概览

## 七、备注（代码事实依据）

- 星标即置顶：`_toggleStar` → `setNotePinned`（`add_edit_note.dart:381`），注释明确"本项目星标即置顶 pinned"。
- 置顶角标：卡片右上角星标（`note_card_body.dart:206`），仅展示不可点。
- 自动保存：退出/后台静默落库，空内容跳过（`add_edit_note.dart:209`、`_onPopInvoked:179`）。
- 配色按序号自动：`NotesColor.getNoteColor(notIndex: index)`，无手动入口。
- 预览禁图：`add_edit_note.dart:514` 隐私考量禁用图片加载。
- 搜索：`home.dart:995` 仅标题+正文字串匹配，无标签维度。
