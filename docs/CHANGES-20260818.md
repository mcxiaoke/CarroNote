## fromSeed 反推 seed 可行性测试（主题色调研）

背景：用户希望 primary 直接等于奶油色 `#FBDD82`，并假设 Material `ColorScheme.fromSeed` 可逆（给 primary 反推 seed）。

结论（已由 `test/reverse_seed_test.dart` 用真实 `ColorScheme.fromSeed` 验证）：
- tonalSpot（默认 variant）下，primary **只继承 seed 的 hue**；
- primary 的 **chroma 被算法固定 ≈36**（`scheme_tonal_spot.dart:29` 写死 `TonalPalette.of(hue, 36.0)`），与 seed chroma 无关；
- primary 的 **tone 被算法固定为 40（亮）/ 80（暗）**（`material_dynamic_colors.dart:245`），任何 DynamicSchemeVariant 都改不了。
- 因此 "primary = 奶油色（tone≈87）" 在数学上不可能通过 fromSeed 得到；fromSeed 对 primary **只有 hue 一维可逆**。
- 要让主色真的是奶油，必须 `ColorScheme.fromSeed(...).copyWith(primary: cream, onPrimary: 深色)` 直接覆盖。

测试运行结果（关键数值）：
- cream seed `0xFFFBDD82` → primary `hue≈93.6, chroma≈36, tone≈39.9` → `#ff715c0c`（深橄榄）
- 同 hue、不同 chroma 的 seed → primary hue 完全一致（证明 chroma 无关）
- 反推 seed → 仍得到 tone≈40 的深橄榄，≠ 奶油
- 遍历 360° hue：最接近奶油的 primary 归一化距离²=0.539，luminance=0.113（奶油≈0.78），证明永远到不了亮色

改动文件：
- 新增 `test/reverse_seed_test.dart`
- `pubspec.yaml` dev_dependencies 增加 `material_color_utilities: ^0.13.0`（仅测试用，不影响发布产物）；已 `flutter pub get`。
