## 集成测试失败修复 + PIN 矮窗布局

> 时间：2026-08-21（GMT+8）

### 集成测试（integration_test/app_test.dart）修复
1. `_loginIfNeeded`：登录按钮先 `ensureVisible` 再 tap。矮横屏（compact-land-890x400）下
   表单在 SingleChildScrollView 内、登录按钮可能在视口外，直接 tap 落空导致登录不触发、
   `_isHome` 断言失败。
2. `_openNavEntry`：桌面 sidebar 与移动 drawer 两个分支都在 tap 前 `ensureVisible`。
   auth re-login 的根因：890x400 宽度 890 走**桌面 sidebar**（非 drawer），锁/设置等底部入口
   在可滚动删栏 ListView 视口外，tap 落空 → 锁定未触发 → 未回到登录页。

### PIN 解锁面板矮窗布局（lib/views/authentication/pin_unlock_panel.dart）
- 紧凑布局判定由 `isCompactLandscape`（仅移动平台横屏）改为按**可用高度**阈值
  `MediaQuery.sizeOf(context).height < 560`。桌面窗口可自由 resize，890x400 矮横屏也会出现
  （此前走非紧凑布局，keyboard 顶部与「Use passphrase」按钮重叠，集成断言 overlap 失败）。
