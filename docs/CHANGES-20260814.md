# 2026-08-14 变更记录

## 新增 WSNS Linux/amd64 一键安装包（2026-08-14 10:10 GMT+8）

为 linux amd64 服务器提供「本地打包 zip → scp → 解压 → 一键安装」流程。

- **`server/deploy/install.sh`**：在目标服务器以 root 运行，把同目录的
  `wsns`（二进制）、`wsns.service`、`config.json` 安装到
  `/usr/local/bin/wsns`、`/etc/systemd/system/wsns.service`、`/etc/safenotes/config.json`；
  自动创建专用用户 `safenotes`、数据目录 `/var/lib/safenotes`、备份目录
  `/var/backups/wsns`；启用并启动服务，最后打印各文件路径与生成的 Token。
  - Token 默认用 `openssl rand -hex 24` 强随机生成；可用 `WSNS_TOKEN=xxx` 覆盖，
    或保留 `config.json` 中已有真实 Token。
  - 支持 `--no-start` 仅安装不启动；无 systemd 时打印手动启动命令。
  - 已有 `/etc/safenotes/config.json` 会先备份为 `.bak.<时间戳>` 再覆盖。
- **`server/deploy/config.json`**：生产配置模板（数据目录/备份/超时/日志），
  Token 用占位符 `__WSNS_TOKEN__` 由安装脚本注入。
- **`server/deploy/package.sh`**：开发机交叉编译 `CGO_ENABLED=0 GOOS=linux GOARCH=amd64`
  并打包 `server/dist/wsns-linux-amd64.zip`（含二进制+服务+配置+安装脚本），
  zip 缺失时回退 7z/tar.gz。
- **`server/deploy/wsns.service`**：`ExecStart` 改为
  `/usr/local/bin/wsns -config /etc/safenotes/config.json`；`ReadWritePaths` 增加
  `/var/backups/wsns`（Tier 2 归档目录）。
- **文档**：`docs/server-implementation.md` §6.6 新增一键安装包说明。

### 验证

- `bash server/deploy/package.sh`：成功产出 `wsns-linux-amd64.zip`，
  内含 `wsns`（ELF 64-bit x86-64 静态链接）、`wsns.service`、`config.json`、`install.sh`。
- `bash -n install.sh` / `package.sh`：语法检查通过。

## Go server 二进制/包名重命名 safeserver → wsns（2026-08-14 09:48 GMT+8）

将 Go 参考服务端的产物名与 Go module 名统一为 `wsns`（含义：WebDAV-compatible
SafeNotes Server），便于分发与跨平台一致。

- **Go module**：`safenotes-server` → `wsns`（`server/go/go.mod` + 全部 `import`
  路径 `safenotes-server/internal/...` → `wsns/internal/...`）。
- **构建产物名**：`server/build.go` 输出 `safeserver-<os>-<arch>[.exe]` →
  `wsns-<os>-<arch>[.exe]`；`server/Makefile` 的 `BIN` 同步改为 `wsns`；
  `server/justfile`、`server/README.md` 注释同步。
- **systemd 服务**：`server/deploy/safeserver.service` 重命名为
  `server/deploy/wsns.service`，内容里二进制路径、`systemctl` 单元名、
  `SyslogIdentifier` 全部改为 `wsns`。
- **开发日志**：`server/go/dev.json`、`dev.config.json` 的 `logFile` 由
  `./temp/safeserver-debug.log` → `./temp/wsns-debug.log`。
- **Flutter 集成测试**：`packages/core/test/sync/safe_server_integration_test.dart`
  的 Go 二进制路径 `$kTestRoot\wsns.exe` 与注释同步；
  `test/scripts/test-cleanup.ps1` 进程匹配新增 `wsns\.exe`（保留 `safeserver\.exe`、
  `safenotes-server\.exe` 历史兼容），日志匹配新增 `wsns-*.log`。
- **文档**：`docs/server-implementation.md`、`docs/sync-feature-design.md`
  （`syncserver` → `wsns`）、`docs/server-backup-design.md`（import 示例）同步；
  `server/README.md` 模块名/服务文件名/产物路径同步。

注意：Dart/CLI 侧的同步后端类型名 `safeserver`（协议概念）与 Node.js 参考实现
（`server/nodejs`，含 `package.json` name 与 node 调试日志）保持不变。

### 验证

- `cd server/go && go build ./...`：通过。
- `git diff` 仅含预期的 import / 产物名改动；`engine_test.go` 等仅 2 行 import
  路径变化（修复了首次 `sed` 误改 CRLF 行尾导致的整文件 diff）。

## 非 shadcn 组件收尾：deleted_notes + sync_diagnostics 等页面替换为 shadcn（2026-08-14 08:57 GMT+8）

承接 `docs/theme-fcs-removal-analysis-20260813.md` 的「低风险高收益」+「中风险」两类
替换（SnackBar 大工程按约定搁置）。FCS 此前已移除，本次只清 Material 组件残余。

- **TabBar/TabBarView → ShadTabs<String>**：`SingleTickerProviderStateMixin` + `TabController`
  移除，改 `_selectedTab` 字符串 + `expandContent: true`（内容撑满）。5 个 tab 设

### 修复：进入 Debug 面板崩溃（2026-08-14 09:20 反馈）

现象：进入面板时 `_LogsTabState.initState` 的 `addPostFrameCallback` 里
`ScrollPosition.maxScrollExtent` 空指针。根因：ShadTabs 默认 `maintainState: true`
让日志 tab 在未选中（Offstage 未布局）时也被提前构建，滚动视图未完成首次布局
（`_maxScrollExtent` 为 null）。修复：

- ShadTabs 设 `maintainState: false`，恢复原 TabBarView「非激活 tab 不常驻构建」语义；
- 自动滚动逻辑加 `position.hasContentDimensions` 防护，未布局时跳过。

  TabBar / TabBarView / showModalBottomSheet 均为 0 处（仅 home.dart 残留一句注释）。
