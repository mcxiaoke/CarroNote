# SafeNotes 变更日志 2026-08-11

## [2026-08-11 09:42] 修复：改密码（含他端改密后重登）后生物识别凭据未更新

- **现象**：修改主密码后，生物识别（指纹/面容）登录提示密码错误；典型触发为他端改密码、本端用旧密码的指纹登录失败后改用新密码重新登录，但 secure storage 中 biometric 凭据仍是旧密码。
- **根因**：`BiometricAuth` 以「当前会话密码」包裹态存于 secure storage（`biometric_auth.dart`）。其刷新只在 `Session.onPasswordSet`（本地改密码页 `change_passphrase.dart:408` 已调用）触发；而**所有密码登录成功的唯一汇聚点 `Session.login`（`session.dart:28`）只写 `PhraseHandler`、从不刷新 biometric**，导致「他端改密 → 本端用新密码重登」这条路径漏刷新。
- **修复**（`lib/models/session.dart`）：`Session.login(passphrase)` 在 `PreferencesStorage.isBiometricAuthEnabled` 为真时调用 `BiometricAuth.setAuthKey()`，把已通过本次登录验证的密码重写进 secure storage。
  - 覆盖场景 1（本地改密码）：`Session.onPasswordSet` 已处理，这里兜底；
  - 覆盖场景 2（他端改密后重登）：重登走 `_onLoginSuccess` → `Session.login(newPassword)`，现会刷新 biometric；
  - 普通密码登录：保证 biometric 凭据始终等于当前有效密码（幂等、无害）；
  - 生物识别登录自身：`_login(await BiometricAuth.authKey)` 也经 `Session.login`，用已解出的当前密码重新包裹（幂等）。
- **安全性**：`Session.login` 仅在登录成功（`_onLoginSuccess`，本地解锁或远端 fingerprint 比对通过）后调用，写入的密码必为已验证正确的当前密码；secure storage 写入为包裹态，不存明文。
- **验证**：`flutter analyze lib/models/session.dart` → No issues found。

## [2026-08-11 01:14] 主密码 KDF 由 PBKDF2 迁移到 Argon2id

- **背景**：PBKDF2 200k 迭代已被内部文档标记为"低于 OWASP 2023 的 600k"（crypto-overview-20260810.md:531）。Argon2id 是内存硬化 KDF，对 GPU/ASIC 暴力破解抗性远强于 PBKDF2；本机 Windows 实测 `32MiB, t=3, p=2` 约 200–330ms，比 PBKDF2 200k（788ms）更快且更抗破解。Argon2id 已随现有 `cryptography` 包内置，零新增依赖。
- **默认参数**（新 vault / 新备份）：`Argon2id(memory=32768KiB [32MiB], t=3, p=2, hashLength=32)`。
- **核心改动**（`packages/core/lib/src/crypto/crypto.dart`）：
  - 新增 `_deriveArgon2id` 与统一分发入口 `deriveKeyFromKdf(password, {required KdfParams kdf})`：按 `kdf.algorithm` 派发——`ARGON2ID` 走 Argon2id（用 memory/parallelism/iterations），其它走 PBKDF2 回退。
  - `deriveMasterKeyAsync` / `deriveBackupKey` 签名改为接收 `KdfParams`（不再收 `salt`/`iterations`）。
  - 常量：`kMkKdfAlgorithm` / `kBackupKdfAlgorithm` 默认值改为 `ARGON2ID`；新增 `kPbkdf2Algorithm` / `kArgon2idAlgorithm` / `kArgon2idMemoryKib` / `kArgon2idIterations` / `kArgon2idParallelism`。
- **KdfParams 扩展**（`sync_models.dart`）：新增 `memoryKiB` / `parallelism` 字段（Argon2id 专用，PBKDF2 为 null），`toJson`/`fromJson` 条件写入；manifest header 序列化已用 `kdf.toJson()` 故自动携带新参数。
- **备份**（`backup_file.dart` / `parse_import.dart`）：`encodeEncrypted` 现用 Argon2id KdfParams 派生并在文件头写入 memory/parallelism；`BackupHeader` 新增同字段与 `kdfParams` getter，`fromJson` 算法校验放宽为接受 `{PBKDF2-HMAC-SHA256, ARGON2ID}`，保证老 PBKDF2 备份仍可导入。
- **keyring / login**（`keyring.dart` / `login.dart`）：`_deriveMk` 及所有调用点改用 `KdfParams`；`changePassword` 在老 PBKDF2 vault 改密码时**自动升级到 Argon2id**（沿用同 salt、不重加密笔记），已是 Argon2id 则沿用；多端 re-auth 经 `unlockFromRemoteManifest(remoteKdf)` 自动适配。
- **兼容性**：存量 PBKDF2 老 vault / 老备份按 manifest/snbak 头中存储的算法字段自动回退，存量数据零重加密迁移。
- **测试**：`crypto_test.dart` 新增 Argon2id 确定性 / 与 PBKDF2 差异 / wrap-unwrap 用例；`backup_file_test.dart` 的 `encodeEncrypted` 增加 `KdfParams? kdf` 覆盖参数（测试用 128KiB 轻量配置加速）。`dart analyze` 无 issue，`crypto_test` / `backup_file_test` 全绿。
- **未改动**：AES-256-GCM 信封格式（nonce12‖ct‖tag16）、dataKey 用法、`SyncCrypto.deriveMasterKey`（PBKDF2）仅作为回退分支保留、无新增第三方依赖。
- **注意（移动端）**：`cryptography_flutter` 仅加速 AES-GCM/PBKDF2，不加速 Argon2id（纯 Dart）。移动端派生耗时可能高于桌面；按决策沿用现有 `deriveMasterKeyAsync` 异步模式，未额外加 `compute()` 隔离。
