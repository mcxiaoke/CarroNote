## 笔记配色色条空白修复（betterui · 22:56 GMT+8）

### 问题（clean build 后用户实测）
- 笔记配色网格里每个 item 的**色条全空白**，顶部预览色条也空白（看不到任何颜色）。
- 其中有一个 item 名为"刷新中"——实为 `notes_color.dart` 里 `prefix: 'Refreshing'` 配色主题，
  经 `assets/translations/zh-CN.json:53` `"Refreshing":"刷新中"` 翻译得名，并非加载状态。

### 根因
- 重写 `_swatch` 时用 `Expanded(child: ColoredBox(color: color))`：在 `Row` 中 `Expanded`
  默认 `crossAxisAlignment: center`，不会把**无 child 的 `ColoredBox`** 纵向拉伸，
  于是色块高度为 0 → 整条不可见（空白）。
- 迁移前（settings_ui 时期）的 `_colorBox()` 用 `Container(decoration: BoxDecoration(color: color), height: boxHeight)`
  显式给定高度，所以正常显示。

### 改动（`notes_color_setting.dart`）
- `_swatch` 改回 `Expanded(child: Container(height: height, color: color as Color))`，
  显式高度保证色块可见（顶部预览与每个 item 共用，一并修复）。
- 主题名 `prefix` 去掉 `.tr()`（原版就没翻译配色名）：避免 "Refreshing" 被译成中文"刷新中"
  造成"加载中"的误会，改为直接显示原文主题名。

### 验证
- `flutter analyze lib/views/settings/notes_color_setting.dart` 0 issues；
  `flutter build windows --debug` √ Built；`flutter run` 启动无崩溃。
- 提交：fix(notes-color): render color swatch with explicit height + drop prefix translation.
