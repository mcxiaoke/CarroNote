# 变更摘要 2026-09-12

> 本文件按项目规范记录当日关键代码变更，最新在顶部。

## 2026-09-12 Windows ICO 生成脚本 gen_windows_ico.py 支持目录输出与自动居中裁切

* **目标**：解决 `gen_windows_ico.py` 在 `-o` 传入目录路径时触发 `PermissionError: [Errno 13] Permission denied` 的问题。
* **修改内容**：
  1. 支持 `-o / --output` 传入目录路径：若输出路径是已有目录或以斜杠结尾，自动使用输入文件的文件名生成同名 `.ico` 写入该目录；若指定路径未含 `.ico` 后缀则自动补全。
  2. 自动递归创建缺失的输出父目录（`os.makedirs(..., exist_ok=True)`）。
  3. 输入图片非正方形时，自动居中裁切为正方形，并打印友好提示，提高脚本容错率。
  4. 增加 Windows 终端 UTF-8 编码重配置，修复终端输出中文乱码。
* **验证**：实测 `python .\scripts\gen_windows_ico.py .\temp\testicon\icon_1024.png -o .\temp\testicon\` 执行成功并生成完整的 7 档尺寸 `.ico` 文件。

## 2026-09-12 图标生成脚本 gen_icon_assets.py 支持 -o/--output 及智能平台生成策略

* **目标**：重构 `scripts/gen_icon_assets.py`，支持 `-o` / `--output` 参数指定输出目录，按 Flutter 标准项目目录结构输出；彻底移除易穿孔的色键抠图；解决平台配置在测试导出和真实项目中的差异化需求。
* **修改内容**：
  1. **智能平台策略区分（测试目录全平台 vs 真实工程精准过滤）**：
     - **测试/导出目录**（指定 `-o` 且目标非已有 Flutter 工程，如空目录、临时目录）：判定为用户输出 icon 测试，**默认启用全平台完整配置（all: android, ios, web, windows, macos, linux & web: true）**，方便用户复制和查看完整配置。
     - **真实 Flutter 工程**（目标目录或当前项目存在 `pubspec.yaml`）：自动检测工程中实际存在的平台目录，仅启用实际存在的平台，其余生成为清晰的注释模板，避免后续 `dart run flutter_launcher_icons` / `flutter_native_splash:create` 运行时因平台目录缺失而抛错。
     - **手动覆盖**：支持 `-p / --platforms` 手动显式指定平台或 `-p all` 强制全开。
  2. **彻底移除色键抠图（color-key）**：改用平滑圆角缩放到 66% 安全区居中策略，杜绝主体穿孔与杂色留存；若母版自带 Alpha 透明底则自动取包围盒居中。
  3. **修正 Inset 缩放参数**：`adaptive_icon_foreground_inset: 0`，防止真机二次缩小。
  4. **几何与色彩加固**：增加非 1:1 图片自动居中裁剪，修复 `lighten()` 在纯白/纯黑下的计算。
* **验证**：在 `temp/testicon` 实测直接输出全平台配置，yaml 中各平台配置完整生效；图像生成细节与色彩完美无损。
