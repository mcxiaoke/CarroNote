## 2026-08-30 15:24 笔记编辑页更多菜单新增 Markdown 预览便捷开关

- **需求**：编辑/预览页 AppBar 右上角「更多」sheet 内新增 Markdown 预览开关，与设置页 `isMarkdownEnabled` 同一 `SharedPreferences` 键值，作为便捷开关。
- **改动**：
  - `lib/widgets/note_actions_sheet.dart`：引入 `PreferencesStorage`，`showNoteActionsSheet` 新增可选回调 `onMarkdownChanged`；`_NoteActionsSheet` 由 `StatelessWidget` 改为 `StatefulWidget`，内部缓存 `_isMarkdownEnabled`（初值 `PreferencesStorage.isMarkdownEnabled`）；`shadSettingsCard` 内插入 `Key('ui-note-action-markdown')` 的 `shadSwitchTile`（icon `LucideIcons.type`，标题 `Markdown`.tr()，描述与设置页一致），`onChanged` 写入 `PreferencesStorage.setIsMarkdownEnabled(v)` 并 `setState` 刷新 sheet，同时回调 `onMarkdownChanged` 供外层即时刷新预览；状态切换不 `pop`，保留 sheet 打开状态可继续操作其他项。
  - `lib/views/add_edit_note.dart`：`_onMorePressed` 记录 `beforeMarkdown`，调用 `showNoteActionsSheet` 时传入 `onMarkdownChanged: (v) => setState((){})` 实现「不关闭 sheet 也能看到底层预览从 `MarkdownBody` ↔ `SelectableText` 即时切换」；关闭后对比 `beforeMarkdown` 与当前值兜底 `setState`，若仅切换开关后关闭（`action==null`）直接返回。
- **Key 复用**：与 `AppearanceSettingsPage` / `DisplaySettingsPage` 的 `isMarkdownEnabled` 同键（`_keyIsMarkdownEnabled`），关闭后预览 `if (PreferencesStorage.isMarkdownEnabled) MarkdownBody else SelectableText` 分支自动生效，与 `_markdownStyleSheet` 联动。
