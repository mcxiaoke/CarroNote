### 发布脚本修复（generate_build_info 引用）
- `scripts/release.py` / `Makefile` / `.github/workflows/flutter-ci.yml` 三处把 `python scripts/generate_build_info.py` 改为
  `dart run scripts/generate_build_info.dart`。原引用指向不存在的 `.py`，会导致 `make release` / CI 第一步即失败
  （实际实现是纯 Dart 脚本，`dart run` 即可）。

### Windows release 构建修复（native assets 下载）
- 根因：sqlite3 3.5.1 的 native assets hook 默认从 GitHub Releases 下载预编译库
  （`https://github.com/simolus3/sqlite3.dart/releases/download/sqlite3-3.5.1/sqlite3.x64.windows.dll`）。
  Dart 的 HttpClient 不读 Windows 系统代理（本机 Clash `127.0.0.1:7890`），直连 github.com 超时
  （`SocketException errno=121`），`flutter build windows --release` 在 native assets 阶段失败。
- 修复：构建前设置 `HTTP_PROXY/HTTPS_PROXY/ALL_PROXY=http://127.0.0.1:7890` 环境变量即可
  （hook 尊重代理 env，见 `CouldNotDownloadException` 提示）；未改动任何仓库代码。
- 验证：设置代理后 `flutter build windows --release` 通过，产出 `build/windows/x64/runner/Release/CarroNote.exe`。
