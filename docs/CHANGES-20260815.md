## 新增：集成测试支持多窗口尺寸巡检（默认 2 种，易扩展）（2026-08-15 14:52 GMT+8）

为在 Windows runner 上以「多种窗口大小」抓布局问题（等价于拖窗口边框 resize），新增尺寸化测试基础设施：

- `integration_test/app_test.dart` 顶部新增命名视口表 `_viewports`（逻辑尺寸 dp），默认两种：`compact-port-400x890`（窄手机，最易暴露 overflow）、`desktop-1280x800`（桌面窗口）。换算：逻辑尺寸 = 物理像素 / (dpi/160)，注释内给出真机 2670x1200@480dpi => 890x400 dp 的加法规格。
- 新增 `_forEachViewport(tester, body)`：在**单个 testWidgets 内**遍历 `_viewports`，每轮 `setSurfaceSize` 程序化 resize 窗口（必须 `await`，否则触发 async-guard 冲突）+ `pumpAndSettle` 重排；每轮先断言 home 在该尺寸下不溢出，再执行 `body`，最后 `_backToHome`；app 全程只启动一次，避免每尺寸重登录。尺寸名传入 `body`，便于写进断言 `reason` 精确定位溢出的尺寸。
- 加新尺寸只需在 `_viewports` 加一行，所有用到 `_forEachViewport` 的 flow 自动覆盖——后人写新集成测试只需 `_loginToHome` 后包一层 `_forEachViewport` 即可获得多尺寸覆盖。
- 笔记流程、设置子页巡检均已改为跨尺寸运行，断言 `reason` 带 `@ 尺寸名`。
- 验证：笔记流程在两种尺寸下通过（+1）；设置巡检**正确捕获**到 `notes_color_setting.dart:128` 的 `RenderFlex` 底部溢出 28px（窄窗 + 桌面平台强制 3 列导致卡片过矮），该 overflow 待修复（后续处理）。
