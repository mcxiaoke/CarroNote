# 2026-08-15 变更记录

## 正确性/风险修复：防重入、键盘处理、批量删除、重置前备份（2026-08-15 10:53 GMT+8）

依据两份 UI/UX 审查报告（`ui-ux-improvement-report-20260814.md` / `ui-ux-review-report-20260814-db.md`）核对结果，落地"正确性/风险类"六项修复：

### 1. 改密码流程防重入 + 方法名拼写修正（`lib/views/change_passphrase.dart`）
- `_finalSublmitChange` → `_finalSubmitChange`（拼写错误，4 处引用）。
- 新增 `_isChanging` 标志：进入异步流程（二次确认/验证/备份/ping/密钥轮换/同步）前置位，`try/finally` 复位；按钮期间禁用并显示 `Processing...`，杜绝连点并发触发密钥轮换。

### 2. 设置密码页防重入（`lib/views/authentication/set_passphrase.dart`）
- 新增 `_isSettingUp` 标志：`_loginController` 入口守卫 + 按钮禁用，避免 PBKDF2（1-2 秒）期间连点并发执行 `initKeyringFromPassword`。

### 3. 笔记保存防重入（`lib/views/add_edit_note.dart`）
- 新增 `_isSaving` 标志：保存按钮期间禁用（`isFormValid && !_isSaving`）；`onSaveCallback` 入口守卫 + `try/finally` 复位；`_onPopInvoked` 保存中不弹未保存框（防止退出拦截重复触发保存产生重复笔记）。

### 4. 登录/设置密码页键盘处理 + GlobalKey 反模式修复（`lib/views/authentication/login.dart`、`set_passphrase.dart`）
- 键盘处理反向移植 change_passphrase 的 `_lastViewInset` 模式：只在键盘"从无到有"时触发滚动，`MediaQuery.of` → `MediaQuery.viewInsetsOf`（细分依赖，重建范围更小）。修复 login 每次 build 无条件触发滚动导致的抖动。
- login 解锁时不再重建 `_formKey`（GlobalKey 重建会丢弃 Form 子树全部状态），改 `_formKey.currentState?.reset()`；`_formKey` 改 `final`。

### 5. 回收站清空改单事务批量删除
- core 包 `database_handler.dart` 新增 `hardDeleteAllDeleted()`：读 uuid → 批量删行 → 批量追加 purged 列表，全部在单个 SQLite 事务内完成（B4：防墓碑从远端复活），替代 UI 层逐条 `hardDelete` 的 N 次事务。
- `lib/views/deleted_notes.dart` `_clearAll` 改调新 API；toast 用实际删除条数。
- 新增测试 `packages/core/test/sync/hard_delete_all_test.dart`（3 用例：只删软删除行/purged 收集/空回收站幂等）。

### 6. 忘记密码重置：删除前自动快照备份（替代"直接删库"）
- 用户反馈原「close → 删库文件 → 清偏好」过于激进。现在重置前先把数据快照到应用数据根目录（`getApplicationSupportDirectory()`，Windows=`%APPDATA%\<app>`，移动端=应用沙箱数据目录）的 `backups/pre-reset-<时间戳>/`：
  - `safenotes_sync.db`：加密数据库文件（字段级 AES-GCM，无密码不可解密）；
  - `preferences.json`：偏好设置 dump（明文，仅 UI/功能开关，不含密钥）。
  - 保留最近 5 份，超出自动清理最旧。
- core 包 `database_handler.dart` 新增 `dbFilePath()`（不打开连接的路径解析，与 `deleteDbFile` 同优先级逻辑）；删除旧 `dbFilePath` getter（打开连接有副作用，仅 log_webserver 一处使用，已同步改为方法调用）。
- 新增 `lib/utils/vault_backup.dart`（`backupVaultBeforeReset()`）；`login.dart` `_performLocalDataReset`：close → **备份（失败则中止重置，绝不允许"备份未完成但数据已删除"）** → 删库 → 清偏好。
- 忘记密码弹窗文案更新为说明自动备份；新增翻译 key（zh-CN / en-US）：`Reset backup saved to: {path}`、`Reset aborted: backup failed: {error}`、`Processing...`、备份说明文案；移除已无引用的旧 key。

验证：`dart run import_sorter:main` + `dart format` 完成；`flutter analyze` 无问题；`dart test`（core）269 过 / 3 失败均为预先存在的环境问题（safe_server 需 Go 编译环境、chaos 需真实数据集，stash 基线复验同样失败）；`flutter test` 35 项全过；`flutter build windows --debug` 成功。
