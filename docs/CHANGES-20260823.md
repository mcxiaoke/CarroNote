## 17:32 修复 Windows 端闲时锁定后窗口偶发抢前台问题

**问题**：用户在其他应用窗口工作时，SafeNotes 闲时自动锁定后会突然跳到前台显示登录窗口（偶发）。

**根因链**：
1. `local_session_timeout` 的空闲 Timer 不感知前后台状态：切到其他应用后超时照样触发，`sessionHandler` 在后台执行 logout 并导航到登录页；
2. 后台路由重建 + 登录页 PIN 覆盖层的 `autofocus` 向 Flutter 引擎发起窗口焦点请求，而 Windows 引擎存在失活窗口被重新激活的已知缺陷（flutter/flutter#187436、PR #188016），导致应用被抢到前台。

**修复**（lib/main.dart）：
1. `_SafeNotesAppState` 混入 `WidgetsBindingObserver`，新增 `_pendingLockEvent` 记录后台触发的超时事件；
2. `sessionHandler` 检测到应用非前台时不再立即导航，仅记录待锁定事件并返回；
3. 回到前台（resumed）时在 `didChangeAppLifecycleState` 中补执行延迟锁定。锁定逻辑幂等：重复事件经 `onTimeOutDo` 的 `isEncryptionEnabled` 检查直接跳过。

**验证**：`flutter analyze` 0 issues；`dart test packages\core\test` 356 项通过；`flutter test` 165 项全部通过。

## 17:19 修复多重连续换行/空行被 Markdown AST 块级解析器折叠吞并问题

**根因与修复**：
1. **连续换行折叠根因**：
   - CommonMark 解析器在处理多个连续空行（如 `\n\n\n\n`）时，会将连续的空行统统折叠合并为单个段落间距（Paragraph Spacing），导致用户留出的多行视觉空白缩水成单行。
2. **精准空行高度占位 (`MarkdownFormatter.prepareMarkdownForRendering`)**：
   - 对非代码块内的空白行（`line.isEmpty || line.trim().isEmpty`）注入 `&nbsp;  ` 占位；
   - `&nbsp;` 在 `flutter_markdown_plus` 中被解码为非断行空格（`\u00A0`），使得每一个空行都拥有完整的单行行高，用户在编辑页空几行，预览页就忠实呈现几行空白；
   - 代码块内部严格保持原样，绝不注入实体。
3. **验证**：
   - `test/markdown_formatter_test.dart` 补充多连续空行测试用例（24 项单测全通）；
   - `flutter analyze` — 0 issues；

## 17:08 解决 Markdown 渲染时纯文本换行丢失合并问题 & 语法特征检测器

**痛点与解决方案**：
1. **换行丢失合并痛点**：
   - 依据 CommonMark 规范，段落内的单换行符（Soft Break）会被默认忽略并合并到同一行中，导致诗歌、便签、日记、地址等多行纯文本在开启 Markdown 渲染时被强行折叠在一行。
2. **现代笔记级预处理算法 (`MarkdownFormatter.prepareMarkdownForRendering`)**：
   - 实现类似 GFM breaks / Obsidian 的换行保护；
   - **代码块保护**：扫描识别 ```` ``` ```` 与 ```` ~~~ ```` 代码栅栏，代码块内部行严格原样输出，绝不污染代码行尾；
   - **非代码文本行硬换行**：对代码块外部的非空、非末尾行自动补齐双空格（`  \n`），使 `MarkdownBody` 忠实呈现用户的自然换行，杜绝行合并；已带双空格或独立空行不重复追加。
3. **高精度 Markdown 语法检测器 (`MarkdownFormatter.isMarkdown`)**：
   - 覆盖标题、任务清单、有序/无序列表、引用、代码块、行内代码、链接/图片、加粗/删除线、分割线、表格 10+ 类语法特征，严格排除普通标点和数字减号等纯文本干扰。
4. **验证**：
   - `test/markdown_formatter_test.dart` 补充语法检测与换行预处理测试组（23 项单测全通）；

## 16:35 修复 Android 选词手势打断问题 & 实现 Markdown 列表回车智能续行与序号自增

**问题根因与修复**：
1. **Android 原生选文字手势打断修复 (P0)**：
   - 根因：`add_edit_note.dart` 在 `initState` 中对 `FocusNode` 挂载了 `addListener(() => setState({}))`，当用户在 Android 触屏上点击、长按选词或拖拽选择手柄时，焦点状态变更触发 `setState` 重建了输入框，导致 `EditableText` 的 `TextSelectionGestureDetector` 手势状态机被重置，系统直接坍塌选区并强制弹出剪贴板浮层。
   - 修复：移除 FocusNode 的全局 `setState` 监听，输入框不再被手势打断，100% 还原 Android 原生选词/拖动手柄流畅体验。
2. **列表回车智能续行与有序列表序号自增**：
   - 需求：用户在有序列表（`1. `）、无序列表（`- `）、待办清单（`- [ ] `）、引用（`> `）输入时，按回车键无法自动续行下一项，有序列表重复出现 `1. `。
   - 实现：编写 `MarkdownAutoIndentFormatter`（`lib/utils/markdown_formatter.dart`），作为 `TextInputFormatter` 拦截回车换行：
     - 有序列表：`1. item` 回车自动生成 `2. `，`2. item` 回车生成 `3. `；
     - 无序列表与待办：回车自动补全前缀 `- ` 或 `- [ ] `；
     - 退出机制：在空列表行（仅含前缀）再次按回车，自动清除当前行前缀并退出列表模式。
3. **测试验证**：
   - `test/markdown_formatter_test.dart` 补充 `MarkdownAutoIndentFormatter` 5 组单测全部通过；
   - `flutter analyze` 零警告；
   - `flutter test` 158 项全通。
