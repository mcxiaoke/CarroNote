## 12:00 getFontColorForBackground 改用 M3 onSurface 色阶

**文件**: `lib/utils/contrast.dart`, `lib/models/app_theme.dart`

### 改动
- `getFontColorForBackground` 优先返回 M3 onSurface 色阶（`#1C1B1F` 深灰 / `#E6E1E5` 浅灰），
  替代原来的纯黑纯白，视觉更柔和。
- 新增 `{bool? isDark}` 可选参数，显式传入暗色模式状态。
- 当中等亮度背景与 onSurface 对比度不足 WCAG AA (4.5:1) 时，回退到纯黑/纯白
  （选对比度更高者，数学上保证 ≥ 4.58:1）。
- `app_theme.dart` 状态栏图标亮度判断从 `appBarFg == Colors.black` 改为
  `appBarFg.computeLuminance() < 0.5`，兼容三种返回值（kDarkForeground / kLightForeground / 纯黑纯白）。

## 11:30 颜色选择器暗色模式双色板 + border 改善

**文件**: `lib/utils/notes_color.dart`, `lib/widgets/note_color_picker.dart`

### 双色板架构
- 新增 `kNoteColorPaletteDark`（11 色），色值与 Google Keep 暗色模式一致：
  `#A02838 #783C24 #885818 #284050 #286070 #246860 #285840 #402858 #683848 #484438 #242426`
- 暗色色板是独立设计的（更饱和、更深、保证白字可读），不是 alphaBlend 计算出来的。
- 新增 `noteColorDarkVariant(lightArgb)` 映射函数：浅色 ARGB → 暗色变体。
- **存储策略不变**：NoteMeta.color 始终存浅色 ARGB 作为"颜色身份"。
- `getNoteColorWithMeta` / `editorBackgroundColor` 暗色模式改用 `noteColorDarkVariant` 查变体，
  替代之前的 `alphaBlend(base, surfaceContainerLow)` 方案。

### 选择器适配
- `_NoteColorSheet` 按当前主题显示对应色板：浅色模式显示浅色圆点，暗色模式显示暗色圆点。
- `_ColorDotGrid` 显示用 `displayColors`（当前主题色板），key 和返回值始终用浅色 ARGB。
- border 宽度从 1px → 2px（未选中态），提高清晰度。
