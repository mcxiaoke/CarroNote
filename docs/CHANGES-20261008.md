# 2026-10-08 变更记录

## 2026-10-08 21:11:23 — fix(auth/diag/android): 登录错误反馈、全局异常全屏呈现、系统分享导出日志、调试Web端6位数字Token及统一VersionCode

### 需求与背景

1. **登录错误感知缺失**：此前未捕获的 Error（如 FFI/符号加载错误）逃逸到 `runZonedGuarded`，而全局 error handler 无 UI 呈现，导致界面无任何提示地卡住；密码登录失败缺少醒目的错误反馈。
2. **调试面板日志导出受限**：原逻辑写入系统下载目录，在 Android 上受限于 scoped storage 或私有应用目录，外部文件管理器无法直接访问，用户导出取证不便。
3. **Web 服务器 Token 过长**：原为 16 字节十六进制随机串（32 字符），移动端/局域网输入极不便。
4. **Android versionCode 被 Flutter 按 ABI 改动**：`split-per-abi` 时 Flutter 默认给不同架构附加前缀，导致不同 variant 的 versionCode 不一致。

### 核心改动

1. **密码登录与认证错误反馈**：
   - `lib/views/authentication/login.dart`：AppBar 在 `DevMode.isActive`（或 debug）时展示 🐞 调试面板入口，确保登录失败或冷启动排查时可随时进入调试面板。
   - 登录失败统一采用顶部红色 SnackBar/Toast（`showErrorToast`）提示错误信息。
   - `_login` 强化 `on Object catch (e, st)` 保护，捕获包括 FFI `ArgumentError` 在内的所有未知异常，并在顶部提示 `Login error: $e`。
   - `lib/sync/sync_service.dart`：`initKeyringFromPassword` 中的 catch 子句拓宽为 `on Object catch (e)`，保证 `ArgumentError` 等底层 Error 转化为 `(success: false, error: ...)` 结构体，不向外穿透逃逸。

2. **全局未捕获异常全屏呈现（Debug/DevMode）**：
   - `lib/main.dart`：暴露 `rootNavigatorKey`。
   - 在 `runZonedGuarded` 的 `(error, stack)` 处理器中，当 `kDebugMode || DevMode.isActive` 时自动展示 `GlobalErrorScreen` 全屏暗色致命错误屏幕，直观显示异常类型、详情、可滚动堆栈追踪，并提供一键复制按钮与重启提示。

3. **系统原生分享导出日志**：
   - `pubspec.yaml`：引入 `share_plus`。
   - `lib/views/settings/sync_diagnostics_page.dart`：状态 tab 导出按钮与日志 tab 下载按钮均升级为调用 `SharePlus.instance.share(...)`，直接唤起系统分享面板（ShareSheet），用户可直接分享至聊天应用、邮箱或另存为文件。

4. **Web 调试服务器 Token 简化**：
   - `lib/src/logger/log_webserver_io.dart`：Token 由 32 位 hex 改为 6 位纯数字随机码（100000 - 999999），并在日志与控制台明文输出，便于局域网设备输入。

5. **Android 所有 ABI 保持统一 VersionCode**：
   - `android/app/build.gradle`：通过 `applicationVariants.all` 显式重写 `output.versionCodeOverride = (flutterVersionCode ?: 1).toInteger()`，彻底消除 Flutter 为 split-per-abi 附加的架构偏移，确保所有 variant 使用相同的 versionCode。
