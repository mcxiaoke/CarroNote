## 1. 品牌定位 / Brand Positioning

### 一句话定位 / One-line positioning

> 萝笺是一款端到端加密的私密笔记应用，让每一页只属于你。
>
> CarroNote is an end-to-end encrypted private note app where every page belongs only to you.

### 定位三支柱 / Three positioning pillars

| 支柱 / Pillar | 中文 / Chinese | 英文 / English |
|---|---|---|
| 隐私优先 | 本地加密优先，不依赖任何第三方云。 | Local-first encryption. No reliance on any third-party cloud. |
| 多端自在 | 自建同步，端到端加密，随处可读。 | Self-hosted, end-to-end encrypted sync, readable anywhere. |
| 温柔克制 | 奶油黄 + 胡萝卜书页，书写本该安心。 | Cream-yellow and carrot-on-paper, writing should feel safe. |

### 目标用户 / Target users

- **注重隐私的普通人**：日记、随笔、灵感、账号备忘，不想被平台窥探。
  *Privacy-aware everyday users*: journals, notes, ideas, credential memos — without platform surveillance.
- **多设备工作者**：手机、平板、电脑之间需要无缝且加密地同步。
  *Multi-device workers*: seamless, encrypted sync across phone, tablet, and desktop.
- **技术爱好者 / 自托管用户**：用 WebDAV 或自建 SafeServer 掌握自己的数据。
  *Tech enthusiasts / self-hosters*: WebDAV or self-hosted SafeServer to own their data.

## 2. 品牌名称 / Brand Name

### 主名称 / Primary name

| 项目 / Item | 内容 / Value |
|---|---|
| 中文名 | **萝笺**（读音：luó jiān） |
| English name | **CarroNote** |
| 组合读法 | 萝笺 / CarroNote |
| 包名建议 | `com.carronote.app` |

### 命名逻辑 / Naming logic

- **萝（胡萝卜）**：取"胡萝卜"的亲昵意象，呼应奶油黄温柔调性与胡萝卜书页图标。
  *Carro-* from carrot: a friendly nod to the cream-yellow tone and the carrot-on-paper icon.
- **笺（书页）**：信笺、便笺、诗笺——私密内容的天然载体，比"笔记"更书卷、更温柔。
  *-Note / 笺* (letter paper): the natural vessel for private content; more literary and gentle than "note".
- **CarroNote**：`Carro` = carrot 简写，全球易拼读；`Note` 直指笔记品类，商店搜索友好。
  *CarroNote*: `Carro` (carrot shorthand, globally pronounceable) + `Note` (category-clear, store-search friendly).

### 为什么是它 / Why this one

在三个主推方案中，**只有「萝笺 / CarroNote」同时满足**：发音顺口、英文好拼、暗藏「胡萝卜 + 书页」双元素、承载 E2EE 加密定位、且中英文零重名。它也是唯一把"胡萝卜+书页"与"加密笔记"两层语义装进 **2 个中文字 + 9 个英文字母** 的名字。

Among the three candidate lines, **only "萝笺 / CarroNote" satisfies all of**: smooth pronunciation, easy spelling, hidden "carrot + page" double meaning, fit with the E2EE positioning, and zero naming conflicts in both languages. It is the only name that packs both "carrot + page" and "encrypted notes" into **2 Chinese characters + 9 English letters**.

### 3.5 品牌故事（可对外发布）/ Brand story (publishable)

> 明代天启年间（1626），有一部名为《萝轩变古笺谱》的孤本——中国木版水印史上最早的笺谱，如今是国家一级文物。
> 「萝」与「笺」，在中国文化里天然就是"书、纸、珍贵内容"的代名词。
> 我们用「萝笺」命名这款加密笔记：让每一页私密，都像古人珍视的信笺一样，只属于写下它的人。
>
> In the Ming dynasty (1626), a single-copy book titled *Luoxuan Biangu Jianpu* — the earliest letter-paper album in the history of Chinese woodblock printing — was made. It is now a Grade-One national cultural relic.
> In Chinese culture, "萝" (vine) and "笺" (letter paper) have always meant *book, paper, and cherished words*.
> We named this encrypted note app "萝笺 / CarroNote": so that every private page, like the letter paper treasured by the ancients, belongs only to the one who wrote it.

## 4. 视觉规范要点 / Visual Guidelines (summary)

> 以下为对外传达时的视觉基线，详细色板见 `lib/data/theme_colors.json`。
> Visual baseline for external communication; full palette in `lib/data/theme_colors.json`.

- **品牌主色 / Brand primary**：奶油黄 Cream Yellow `#F7DC9F`（主题库默认暖黄）。
- **点缀色 / Accent**：胡萝卜橙 Carrot Orange（图标胡萝卜主体），米色信纸 Paper Beige（笺纸底）。
- **图标意象 / Icon motif**：一页米色信纸 + 角上一根胡萝卜，呼应"书页 + 胡萝卜"双元素。
- **明暗 / Modes**：支持浅色 / 深色主题，奶油黄为默认浅色基调。
- **气质 / Tone**：温柔、克制、不幼化；与"加密隐私工具"的专业感并存。
  Gentle, restrained, not childish; coexisting with the professionalism of a privacy tool.

## 6. Internal strategy: naming evaluation & trademark path (not public)

### 6.1 候选名检索结论 / Search findings

| 候选 / Candidate | 中英文重名情况 / Conflict status | 结论 / Verdict |
|---|---|---|
| 萝卜笔记 / CarrotNotes（原版） | **已占**：iOS `com.robotpen.carrotnote`（罗博智能笔，2021 上架，175 国）；Android `com.xzydj.carrotnote` | 弃 / Drop |
| 萝存 / CarroVault | **已占**：iOS `CarVault App`（汽车收藏类 v1.6.5）；Vault 品牌红海 | 弃 / Drop |
| 甜萝笔记 / SweetCarro | **已占**：「甜萝」为微信/QQ 美化插件 v7.0.1（`com.sweet`），用户认知错位 | 弃 / Drop |
| **萝笺 / CarroNote** | **无应用冲突**；「萝轩变古笺谱」为文化文物（不同类目，可作资产） | **定 / Pick** |
| 页萝 / PageCarro | 未占，但"页"多音字、语序略生 | 备选 / Backup |
| 蜜萝 / HoneyCarro | 未占，但缺"页/笺"书页元素 | 备选 / Backup |

### 6.2 商标与域名待办 / Trademark & domain checklist

- [ ] 中国商标网第 9 类（可下载软件）+ 第 42 类（网站/SaaS）检索「萝笺」。
- [ ] 域名：`carronote.app`（主）、`carronote.com`（备用）、`carronote.cn`（国内）。
- [ ] App Store / Google Play 关键词检索 `carrot / carro / note / 加密 / 笔记 / 私密` 是否撞名。
- [ ] 包名锁定 `com.carronote.app`，为同步服务 / CLI 工具预留子域与扩展。

### 6.3 商标被占时的退路 / Fallbacks if "萝笺" is taken

1. **萝简 / CarroSheet** —— 简=竹简/书简，比"页"更书卷、比"笺"更白话。
2. **半笺 / CarroNote** —— 极简品牌，"半笺"= 寸页信笺，意境美，海外沿用 Note 主体。
3. **笺萝 / NoteCarro** —— 把核心词 `Note` 置于英文首位，语序更顺（jiān luó）。
