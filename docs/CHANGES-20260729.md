## [2026-07-29 13:24:10] - 修复：旧 db 存在时输入密码后 UI 一直转圈

- **根因**: `set_passphrase.dart` 的 `_loginController` 在 `_initVault` 失败后没有阻止导航到 `/home`（与 `login.dart` 不一致）。当 SharedPreferences 被清除但 db 文件还在时（如卸载重装），用户输入两次新密码后 `Vault.unlockLocal` 用新密码解旧 `encryptedDataKey` 失败抛 `WrongPasswordException`，但 UI 仍导航到 `/home`，此时 `database._dataKey` 为 null，`refreshNotes` → `readAllNotes` → `_decryptField` 抛 `DataKeyNotSetException`，异常未捕获导致 `isLoading` 永远为 true，UI 一直转圈。新建笔记后 pop 触发 `refreshNotes` 同理会卡住。
- **主修复（root cause）**: `lib/views/authentication/set_passphrase.dart` 的 `_initVault` 改为返回 `Future<bool>`，`_loginController` 在失败时 `return` 不导航（对齐 `login.dart` 的 `_login` 模式）。失败时显示 snackbar 提示"加密初始化失败"并停留设置密码页。
- **防御层（defense-in-depth）**: `lib/views/home.dart` 的 `refreshNotes` 加 `try/finally`，任何异常都会清空笔记列表、snackbar 提示并确保 `isLoading=false`。防止未来其他异常路径（dataKey 不匹配、db 损坏、迁移进行中）再次出现"永远转圈"。
