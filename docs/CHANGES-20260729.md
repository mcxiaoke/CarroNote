## [2026-07-29 21:54:52] - 修复共享 blob 解密失败（blob AAD 协议 v2 + 去重自愈）

- **问题**: 客户端 A（Windows）每次同步报"1 条笔记因密钥不匹配未能同步"，实际与密钥/改密码无关。
- **根因**: 内容寻址去重与 AAD 设计冲突。Android 端存在两条内容完全相同的笔记（`f35fbbdd`/`a7dddd50`，同 contentHash `90d1fe13`），blob 按内容 hash 寻址 → 共享同一个 blob 文件；但 blob 加密 AAD 绑定的是 uuid（上传者 `f35fbbdd`），A 下载 `a7dddd50` 用自己 uuid 当 AAD 解 → GCM tag 必然失败；A 无该 uuid 明文 → Layer 2b 无法自愈 → 永久失败循环。任何内容重复的笔记都会让第二台设备踩坑（协议级缺陷）。
- **修复方案**:
  - **协议 v2（lib/sync/sync_engine.dart）**: blob 加密 AAD 从 uuid 改为内容 hash（与内容寻址自洽，`_uploadNote`）；下载与冲突副本保留处新增 `_openBlobEnvelope` 双重解密（先 AAD=hash 新格式，回退 AAD=uuid 兼容存量 blob，无需迁移远端数据）；防信封错位由既有 M7 校验（解密内容 hash == manifest 记录 hash，manifest items 经 dataKey 加密认证）保证，安全性不降级。
  - **去重自愈（lib/sync/sync_engine.dart + lib/data/database_handler.dart）**: `_handleDownloadFailure` 在无同 uuid 明文时，查找本机 content_hash 相同的"孪生笔记"（新增 `readNoteByContentHash`），用孪生明文物化该 uuid 到本地并按 v2 协议重传共享 blob，全网治愈。
- **测试**: `test/sync/webdav_integration_test.dart` 新增"共享 blob"组 3 测试（v2 共享 blob 新设备全量下载 / v1 旧格式兼容下载 / v1 存量共享 blob 复现线上故障 + 孪生自愈 + 第三设备端到端）；更新 P2a/P3 断言为 v2 AAD。

## [2026-07-29 19:52:00] - 修复改密码多端同步问题链（BUG-1~4 / B1-2 / B3 / B4）

- **问题**: A 端改密码时 B 端（旧密码会话）开着，点同步/新建笔记均"正常"且毫无密码变更提示；B 重启后旧密码无法登录、新密码可登录、UI 全程无提示。推测"某个 meta 被 remote 覆盖"。
- **根因**: 多端改密码场景的密钥纪元（`keyVersion`/`keyFingerprint`/`encryptedDataKey`）协调缺陷 + 无 UI 提示，分四类：
  - BUG-1/2：纪元守卫触发时，旧密码设备构建上传 header 只用本地 meta（旧 `encryptedDataKey`/fingerprint），把远端新纪元回滚，导致"翻转战争"（远端 keyVersion 被反复覆盖）。
  - BUG-3：H1 回写分支只更新本地 `encryptedDataKey`，未整体收敛 `keyVersion`/`keyFingerprint`，远端 header 可能变成 fp=旧/edk=新 的自相矛盾，新密码判别失败，并误报 `passwordEpochMismatch`。
  - BUG-4：同步结果里的 `passwordEpochMismatch` 从未被 UI 消费，用户全程无提示。
- **修复方案**:
  - **lib/sync/sync_engine.dart（B1-2）**：纪元守卫触发时（远端 `keyVersion` > 本地），上传 header 的**密钥纪元三元组**（`encryptedDataKey` + `keyFingerprint` + `keyVersion`）整体采用远端值，不再回滚远端新纪元，消除翻转战争。
  - **lib/sync/vault.dart + lib/sync/sync_engine.dart（B3）**：新增 `Vault.adoptRemoteEpoch`（整体写回远端三元组到本地 meta 与内存）；H1 分支在他端改密码 + 本端新密码登录时整体收敛本地纪元，`epochMismatch` 不再误报。`keyFingerprint`/`keyVersion` 由 `final` 改为可变以支持同步时采用远端纪元。
  - **lib/views/home.dart（B4）**：`HomePage` 订阅 `SyncService.stateStream`，消费 `SyncResult.passwordEpochMismatch` 弹窗"密码已在其他设备修改"，提供"稍后/退出并重新登录"；复用既有的安全登出顺序（`stopListening` → `pushNamedAndRemoveUntil('/login')` → `Session.logout`），只清内存密钥、不删本地 DB。
