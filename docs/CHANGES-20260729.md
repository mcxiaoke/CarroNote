## [2026-07-29 10:25:31] - 收尾修复：D3/F4/注释/解锁顺序

- **crypto.dart 注释修正**: 顶部注释仍写 `FIXED_SALT / safenotes-v1`，与已落地的 per-vault salt 实现矛盾。改为描述 per-vault 随机 salt 机制，并补充历史演进说明（v0 vaultId salt → v1 固定 salt → v2 per-vault salt）。
- **Vault.unlockFromRemoteManifest 脆弱性修复**: 原实现先持久化远端 meta 再验证密码，密码错误时本地 meta 已被覆盖。改为先 `_unlockWith` 验证密码（失败抛 `WrongPasswordException`），验证成功后才持久化 meta，保证错误密码不污染本地状态。
- **D3 修复: pendingBlob 持续失败导致 manifest version 无意义攀升**: 新增 `_hasEffectiveChange()` 方法，在 PUT manifest 前判断是否有实际变更（upload/download/delete 操作、纪元不匹配、encryptedDataKey override、header 关键字段变化、items 不一致）。无实际变更时跳过 PUT，version 不递增。跳过 PUT 时仍执行 GC（场景：无 manifest 变更但有孤儿 blob 需清理）。
- **F4 修复: reEncryptAllNotes 迁移期间 UI 读锁**: 新增 `MigrationInProgressException` 异常类和 `_isMigrating` 标志。`reEncryptAllNotes` 期间置 true，`readNote`/`readNoteByUuid`/`readAllNotes`/`readDeletedNotes`/`storeNote`/`updateNote`/`updateNoteByUuid` 调用 `_checkNotMigrating()` 守卫，迁移中抛异常。`readAllNotesIncludingDeleted` 不加守卫（同步引擎内部用，且 `reEncryptAllNotes` 自身需调用）。`finally` 块清除标志，保证异常时也恢复。
