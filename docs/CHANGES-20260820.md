# 变更摘要 2026-08-20

## 字体大小档位文案精简 + 标签单行显示

- `lib/utils/editor_text.dart`：档位名 `Extra Large` 改为 `Extra`（`_names`）。
- `assets/translations/en-US.json` / `zh-CN.json`：档位名调整为 小号/标准/大号/特大（`Small`/`Standard`/`Large`/`Extra` 键），不再显示字号数字。
- `lib/views/settings/editor_font_setting.dart`：字体大小 segment 标签去掉 px 数字，只显示档位名；字体类型/大小 segment 标签均加 `maxLines: 1` + `TextOverflow.ellipsis`，杜绝标准/特大等宽标签因均分宽度不足而换行成两行（根因：`SegmentedButton` 的 `expandedInsets` 按 容器宽度/段数 均分，Extra 档固有宽度 ~214px 超过每段 ~163px）。

## 字体样式页改用 Material SegmentedButton

`lib/views/settings/editor_font_setting.dart`：字体类型与字体大小选择改用 Material 原生 `SegmentedButton`（替换自绘 `ShadSegmentedGroup`，shadcn 无对应组件，自绘控件存在布局问题）。

- 字体类型 3 段、字体大小 4 段均单选中，`expandedInsets: EdgeInsets.zero` 撑满整行，`showSelectedIcon: false` 关闭勾选图标；样式 `_segmentStyle` 保持与旧控件接近：选中段填充主题主色、未选段透明、圆角边框。
- 回调签名由 `int?` 改为 `Set<int>`（`onSelectionChanged`），空集时保持不变。
- 删除 `lib/widgets/shad_segmented_group.dart`（已备份至 `temp/backups/`），全工程无残留引用。
- 校验：`flutter analyze` 通过；`dart test packages\core\test` + `flutter test` 全部通过。
