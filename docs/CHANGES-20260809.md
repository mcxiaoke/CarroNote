# 变更日志 (2026-08-09)

## [2026-08-09 09:17] 主题引擎切换：接入 flex_color_scheme 作可插拔主题引擎，移除 dim 主题（提交 9b36ea6）
- **方案**：方案 B——弃用 Nord 硬编码 `ThemeData`，改用 Material Design 3 + `flex_color_scheme` (FCS) 作为统一主题引擎；只保留亮/暗两套主题，简化此前 Nord 的 light/dim/out 多暗色变体。
- **插拔点设计**（`lib/models/app_theme.dart`）：FCS 仅在 `AppThemes` 被引用，注释明确"业务代码一律通过 `Theme.of(context).colorScheme.*` 取色，不直接依赖任何主题库"。将来要替换主题引擎（如换用其它配色方案库），只需重写 `AppThemes` 一处，UI/组件层零改动——满足"可替换可插拔"诉求。
- **种子色与生成**：品牌种子色 `_brandSeed = Color(0xFF5E81AC)`（Nord frost 蓝调，换主题库通常只改这一处）；`ColorScheme.fromSeed(seedColor:_brandSeed, brightness)` 生成对比度合规的 M3 调色板，再交给 `FlexThemeData.light/dark(colorScheme: scheme, useMaterial3:true, textTheme/primaryTextTheme: NotoSerif)` 包装（应用表面色调、组件默认值等增强）。
- **移除 dim 暗色变体**（`lib/views/settings/theme_setting.dart`）：删除"暗色变体选择"bottom sheet 及其 `CupertinoCheckListTile`、`setModalStateDarkTheme`、`DarkThemeEnum` 等；`ThemeProvider` 移除 `setIsDarkDimTheme` 方法。现设置页仅保留"Dark 模式开关"与"跟随系统开关"。`darkSettingsScaffold`/`darkSettingsCanvas` 简化为 `Colors.black`/`Colors.grey.shade900`。
- **依赖变更**：`pubspec.yaml` 新增 `flex_color_scheme: ^8.4.0`（要求 Flutter ≥3.44.0 / Dart ≥3.12.0）。注意：`safenotes_nord_theme` git 依赖**暂未移除**——其 `NordColors.*` 仍散落在其它文件，待 提交B 清理这些调用后再从 pubspec 删除（避免拆用报错）。
- **验证**：`flutter analyze lib` → No issues found。建议桌面大屏（≥600 宽）亮/暗双模式实机回归，重点确认左侧 `HomeSidebar` 与设置页文字/图标对比度正确。
