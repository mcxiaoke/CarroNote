## note_meta 数据层（阶段 1）实现与测试

> 设计文档：`docs/feature-note-meta-design.md` · 进度：`docs/PROGRESS-note-meta.md`

### 新增
- `packages/core/lib/src/models/note_meta.dart`
  - `NoteMeta` 模型 + `NoteMetaFields` + `tableNoteMeta` 常量。
  - payload 明文 JSON 序列化（`encodePayload`/`decodePayload`，容错不抛），
    `extra` 顶层键透传（前向兼容 + 零成本扩展）。
  - `normalizeTags`（去空白/丢空串/去重）、`copyWith`、`toRow`/`fromRow`、
    `defaults(uuid)`。调试 `toString` 不打印 tags / payload 内容。
- `packages/core/test/db/note_meta_test.dart`：14 项单测全通过。

### 修改
- `packages/core/lib/core.dart`：导出 `note_meta.dart`。
- `packages/core/lib/src/db/database_handler.dart`：
  - 抽出 `_schemaVersion = 5`；`_onUpgrade` 加 `oldVersion < 5` 分支
    （`CREATE TABLE IF NOT EXISTS note_meta`，不碰 notes 表）。
  - `_createNoteMetaTable` **单一建表副本**接入 `_createDBStatic` /
    `_createDB` / `_onUpgrade` 三处（从结构上消灭漏改风险）。
  - `_metaCache`（`Map<String,NoteMeta>`）与 `_notesCache` 完全隔离；
    `_invalidateCache` 一并清理；切 pinned 零笔记解密。
  - meta CRUD：`readAllNoteMeta` / `getNoteMeta` / `upsertNoteMeta` /
    `setNotePinned` / `setNoteTags` / `readAllTags` + 事务版墓碑
    `_markNoteMetaDeletedInTxn`（顺带擦除 payload，防标签明文残留）。
  - 硬删除三处（`hardDelete` / `hardDeleteByUuid` / `hardDeleteAllDeleted`）
    事务内写墓碑 + 事务后清缓存。
  - `reEncryptAllNotes` 同步重加密 `note_meta.payload`（新增
    `_readMetaPayloadsPlain`），修复 dataKey 轮换后标签永久无法解密的隐患。
  - payload 加入 `_inspectorHiddenColumns`（不打印密文）。

  未设置环境变量时自动 skip，仓库内不保存任何路径与口令。

### 红线核对
- 未触碰 `SafeNote.computeHash` / `toContentBytes` / `fromContentBytes` / blob AAD。
- 元数据变更只动 `note_meta.updated_at`，不改 `notes.updated_at` / `content_hash`。
- note_meta 无 `REFERENCES notes ... CASCADE`（墓碑须在 notes 行消失后存活）。
