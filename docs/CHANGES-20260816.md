## 修复 Drawer 头部 logo 溢出（集成测试 400x890 报错）

文件：`lib/widgets/drawer.dart`

**根因**
- `_drawerHeader` 用 `MediaQuery.sizeOf(context).width * 0.25` 计算 logo 尺寸。
- 集成测试 `setSurfaceSize(400, 890)` 只改 `View.physicalSize`，**MediaQuery 仍返回
  真实窗口宽**（约 1265），logo 被算成 ~316，塞进仅 272 宽的 Drawer 内容区 → 右侧
  RenderFlex 溢出 44px（集成测试在经 Drawer 打开 settings 时触发，报在
  `ui-setting-item-darkmode` 瓦片）。

**修复**
- 改用 `LayoutBuilder` 读取 Drawer 实际约束宽度计算 logo：`constraints.maxWidth * 0.25`，
  与 home.dart 的响应式断点方式一致，不再依赖 MediaQuery 屏幕尺寸。
- 抽屉顶部/底部留白与菜单间距由 MediaQuery 高度百分比（`height*0.07/0.01/0.005`）
  改为固定 token：`AppShape.inputHeight`(48) / `AppSpace.sm`(8) / `AppSpace.xs`(4)，
  彻底摆脱 MediaQuery 高度依赖。
- 清理已无用的 `_drawerHeader` 的 `orientation` 参数与整个 `OrientationBuilder`。

## 笔记页 预览/编辑模式 视觉对齐（颜色 / 字体 / 分隔线）

文件：`lib/views/add_edit_note.dart`

**根因**
- 颜色：编辑态标题/正文由 `ShadInputFormField` 注入 `ShadTheme.colorScheme.foreground`；
  预览态 `SelectableText`/Markdown 用 `AppText`（无 color），落到 Material `bodyMedium`，
  亮色偏灰、暗色偏亮，造成预览/编辑色差。
- 字体：编辑态实际落到 `shad textTheme.muted` 字体；预览态 `AppText`（fontFamily=null）
  继承 Material 默认字体（如 Roboto），对 `#` 等符号的宽窄/粗细不同，Android 上尤为明显
  （`uiFontFamily` 为 null 未生效）。
- 布局：预览态标题→正文原为 `SizedBox(10)` 无分隔线，编辑态为
  `SizedBox(8)+Divider(1)+SizedBox(8)`，切换时正文位移 7px 且分隔线闪现。

**修复**
- 颜色：预览标题、纯文本正文、`_markdownStyleSheet` 的 `p`/`h1`–`h5` 统一取
  `ShadTheme.of(context).colorScheme.foreground`（`h6`/blockquote 保留 M3 弱化色）。
- 字体：新增 `_editorLikeStyle(context, base)` 复刻编辑态有效样式
  `shad.textTheme.muted.copyWith(color: foreground).merge(base)`，预览标题/正文及
  Markdown `uiBase` 直接复用，与编辑态逐像素一致。
- 布局：预览态标题→正文改为与编辑态同构的 `SizedBox(8)+Divider(1)+SizedBox(8)`，消除跳动。

**已知差异（行高，未修）**
- 编辑态 `RenderEditable` 自动套 `StrutStyle` 强制最小行高，预览态 `RenderParagraph` 无
  strut，Android 上 CJK 整篇偏高约 4.6%（Inspector 实测正文 13780 vs 13178，差 602px）；
  Windows 上无差异。曾尝试在预览态加 `strutStyle` 对齐，hot reload 验证仍有偏差且非关键，
  已回退，仅保留上述字体/颜色/分隔线对齐。

**验证**：`dart analyze lib/views/add_edit_note.dart` 无报错。
