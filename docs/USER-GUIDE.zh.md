CarroNote 使用指南

> CarroNote ，安心写下每一笺。

欢迎使用 CarroNote ！这是一款注重隐私的加密笔记应用。这份指南会带你从第一次打开，一步步熟悉它的全部功能。别担心，全文都用大白话，不需要任何技术背景。

---

## 一、先认识一下 CarroNote 

在开始之前，先用几句话了解它最特别的地方：

**🔐 端到端加密 —— 你的笔记，只有你能看**

你写的每一条笔记，在保存的那一刻就已经被加密了。即使有人拿到你的手机，或者（开启同步后）中途截获数据，看到的也只是一堆乱码。连我们都看不到你的笔记内容。

**📱 本地优先 —— 没网也能用**

笔记默认就存在你自己的设备上，而且是加密存储的。飞机上、地铁里、没信号的地方，随时都能记。

**☁️ 多端同步 —— 换设备也不丢**

想在家里电脑和手机之间同步笔记？可以。加密后的笔记通过你指定的方式同步，服务端只能看到密文，永远拿不到明文。

**🎨 多彩主题与彩色笔记 —— 把它变成你喜欢的样子**

浅色、深色随意切换，还有上百种主题色、十几套笔记配色，让记笔记也赏心悦目。

**🔒 多重隐私保护**

指纹 / 面容解锁、防截屏、隐身键盘、闲置自动锁定、暴力破解防护……从各个细节保护你的隐私。

## 二、第一次使用：设置主密码

第一次打开 CarroNote ，你会看到一个「设置密码」的页面。这是所有安全的基础，请认真对待。

1. 输入你想设置的主密码（密码至少 8 位，太简单的密码会被提醒加强）。
2. 再输入一遍确认。
3. 点击「确认」。

**⚠️ 非常重要：请务必牢记这个密码。**

它是打开你所有笔记的唯一钥匙，只存在于你的脑子里。一旦忘记，任何人都无法帮你找回——包括我们。没有密码，笔记就永远无法解密了。

> 小贴士：密码可以是一句话、一组有意义的词组，比单纯的数字组合更安全，也更好记。

设置完成后，你就进入了主界面，可以开始写第一条笔记了。

## 三、登录与解锁

以后每次打开 CarroNote ，你都需要解锁，有两种方式：

**方式一：输入密码**

在登录页输入你的主密码，点击「登录」即可。

**方式二：指纹 / 面容解锁**

如果你在设置里开启了生物识别，登录页会多出一个「生物识别」按钮，按一下指纹或看一眼屏幕就解锁了，不用每次敲密码。

> 为了让你不忘记密码，每隔几次指纹解锁， CarroNote 会提醒你用密码登录一次。这是正常的，也是在保护你。

**忘记密码了怎么办？**

登录页下方有一个「无法解密」的提示。如果确实忘记了密码：

1. 点击它，会看到「清空本地数据重新开始」的选项。
2. 这是最后的办法——它会删除本机所有数据，让你重新开始。
3. 好消息是：重置前会自动保存一份加密快照，万一以后想起来密码，还能手动恢复。

> ⚠️ 清空本地数据是不可逆的操作，请三思。

## 四、写笔记：新建、编辑、保存

**新建笔记**

点击主界面右下角的 ➕ 按钮，进入新建笔记页面。

**笔记的结构**

每条笔记有两部分：

- **标题**：笔记的名字，一眼看出这条笔记讲什么。
- **正文**：笔记的内容，写什么都行。

**编辑与预览**

打开一条笔记后，默认先看到的是「预览」效果（排版后的样子）。点击右上角的笔形图标，切换到「编辑」模式开始写；再点眼睛图标，切回「预览」。

**保存**

写完点击右上角的 💾 保存图标即可。

> 如果忘了保存就想退出， CarroNote 会弹窗问你：保存、还是放弃、还是继续写。不用担心手滑丢失内容。

**删除笔记**

在编辑页右上角点 🗑️ 垃圾桶图标，确认后笔记会被移入回收站（不会立刻消失，还有反悔的机会）。

## 五、用 Markdown 排版你的笔记

 CarroNote 支持 Markdown，让你用简单的符号写出有格式的笔记。

**什么是 Markdown？**

Markdown 是一种「用符号标记格式」的写法。比如：

| 你想实现的效果 | 这样写 |
|---|---|
| 一级标题 | `# 标题` |
| 二级标题 | `## 标题` |
| **加粗** | `**加粗**` |
| 引用 | `> 引用文字` |
| 行内代码 | `` `代码` `` |
| 代码块 | 用 ` ``` ` 包裹 |
| 链接 | `[文字](网址)` |

写好后切到「预览」，就能看到排版效果。

**开启 / 关闭 Markdown**

在 设置 → 外观 → Markdown，可以随时开关。关闭后，笔记正文会以纯文本方式显示。

> 🔒 隐私提示：出于安全考虑， CarroNote 不会自动加载笔记里的图片，也不会自动联网。链接只在你主动点击时才用系统浏览器打开。

## 六、搜索与整理笔记

**搜索**

主界面顶部有搜索框，输入关键词，就能同时匹配标题和正文，快速找到想要的笔记。

**列表 / 网格视图**

右上角可以切换「列表」和「网格」两种显示方式，看你喜欢哪种。

**排序**

右上角的箭头按钮，可以切换「新的在前」或「旧的在前」。更细的排序方式（按修改时间 / 按创建时间）在设置里调整。

## 七、回收站

删掉的笔记都进了「最近删除」（回收站），在主菜单里可以找到。

- **恢复**：点笔记右上角的「⋯」菜单，选「恢复」，笔记回到列表。
- **永久删除**：选「永久删除」，彻底删除，无法恢复。
- **清空全部**：右上角垃圾桶图标，一次性清空回收站。

> ⚠️ 永久删除和清空都无法撤销，请确认后再操作。

## 八、同步：让笔记在设备间流动

同步可以让你在手机、平板、电脑之间共享同一份笔记。因为全程端到端加密，同步时传输的也都是密文。

**开启同步**

进入 设置 → 数据 → 同步设置，打开「启用同步」。

**选择同步方式**

点击「同步配置」，有几种选择：

- **本地文件夹**：把加密数据同步到本机某个文件夹（适合测试或单设备备份）。
- **WebDAV**：适合坚果云、NextCloud 等网盘或自建服务，需要填服务器地址、账号、密码（网盘通常要填「应用密码」而不是登录密码）。
- **SafeServer**：如果你自己搭建了配套的同步服务，填地址和令牌即可。
- **不同步**：关闭同步，数据只留在本机。

填好后，点击「测试连接」，通过后再点「保存」。

**自动同步 / 手动同步**

- 打开「笔记改动后自动同步」，每次改完笔记就会自动同步。
- 也可以随时回到同步设置，点「立即同步」手动拉一次。

**看懂同步图标**

主界面右上角的云朵图标代表同步状态：云朵转圈 = 同步中，带勾 = 成功，红色断开 = 失败。

## 九、备份与迁移

**自动备份**

设置 → 数据 → 备份，打开「自动备份」， CarroNote 会定期帮你把加密数据备份到指定位置。

**立即备份**

在备份页点「立即备份」，立刻生成一份备份文件。

**导出 / 导入备份**

- **导出备份**：把笔记打包成一个文件，可选择加密导出（需要设一个导出密码）或明文导出。
- **导入备份**：在新设备上导入之前导出的备份，轻松搬家。

> 备份文件默认也是加密的，别人拿到也读不了。

## 十、主题与外观（把它变好看）

进入 设置 → 外观，这里能自定义整个界面的样子。

**深色模式**

点「深色模式」，可以选择手动开启 / 关闭，也可以「跟随设备设置」——手机切换深色， CarroNote 跟着变。

**主题颜色**

点「主题颜色」，进入选色页。这里把颜色分成几大色系（通用、马卡龙、活力、自然、深邃），上百种颜色任你挑。

- 点一下颜色只是「预览」，顶部会显示效果。
- 确定后点底部的「应用主题」按钮，整个界面立即换装。

**笔记颜色**

点「笔记颜色」，可以给笔记卡片上色：

- 打开「彩色笔记」开关，笔记会根据位置自动轮换配色。
- 下面有十几套配色方案（北极、和谐、绽放……）供你选择。
- 也可以关掉彩色，让所有笔记保持统一的素雅底色。

**其它外观选项**

- **紧凑笔记**：让笔记卡片显示得更紧凑，一屏能看更多。
- **Markdown**：上面说过了，控制正文是否用 Markdown 排版。
- **相对时间**：开启后时间显示为「5 分钟前」，关闭则显示具体日期。
- **按修改时间排序**：控制笔记默认按「最后修改」还是「创建时间」排序。

## 十一、安全与隐私设置

进入 设置 → 安全，这里集中了所有保护隐私的开关。

**生物识别**

开启后，可以用指纹 / 面容解锁 CarroNote （开启前会先验证一次你的生物识别）。

**闲置自动锁定**

打开后，当你一段时间没操作， CarroNote 会自动锁定，需要重新解锁才能进入。时长可选 30 秒到 15 分钟。

**安全显示（防截屏）**

开启后， CarroNote 的界面会被系统标记为「安全内容」，阻止后台快照和截图，防止别人偷看。

**隐身键盘**

开启后，输入法不会记录你在 CarroNote 里输入的内容，降低被键盘「学习」你敏感信息的风险。

**修改主密码**

在这里可以更换你的主密码（需要先输入旧密码）。

## 十三、常见问题（FAQ）

**1. 忘记主密码了怎么办？**

无法找回。只能在登录页选择「清空本地数据重新开始」（重置前会自动保存加密快照，若日后想起密码可尝试手动恢复）。

**2. 同步安全吗？别人能看到我的笔记吗？**

安全。笔记在离开你的设备前就已经加密，同步服务端只能看到密文，看不到明文。

**3. 换了新手机，怎么把笔记搬过去？**

用「导出备份」把笔记导出成文件，再在新手机上「导入备份」，或直接配置同一个同步后端自动拉取。

**4. Markdown 里的图片为什么不显示？**

出于隐私考虑， CarroNote 不会自动加载图片（避免泄露你的网络位置等信息）。这是有意为之的设计。

**5. 我删的笔记能找回吗？**

普通删除会进「回收站」，可以恢复；只有「永久删除」或「清空回收站」后才真正无法恢复。
