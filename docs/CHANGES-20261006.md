## 2026-10-06 20:05:37 — fix(core): 坚果云 WebDAV If-Match 412 假冲突兼容

### 背景

用户切换到坚果云（dav.jianguoyun.com）后同步必然失败，报"乐观锁冲突超过 3 次：
ConflictException: WebDAV If-Match failed: 412"。诊断快照证实：坚果云 GET manifest
返回稳定 ETag，但 PUT 带 If-Match 一律 412——即使远端内容从未变化（三次重试 GET
内容指纹/ETag 完全一致）。即坚果云的 If-Match 校验与其对外 ETag 不一致，乐观锁
在该服务上不可用。文件头注释原"坚果云完整支持 If-Match"的声明与实测不符，已更正。

### 修复（packages/core/lib/src/sync/backends/webdav_backend.dart）

仅对坚果云域名族（`*.jianguoyun.com` / `*.nutstore.net`，同一服务端国际版）启用，
其他 WebDAV 服务行为完全不变：

- `getManifest`：记录最近一次 200/404 响应的远端密文作为基线（`_lastRemoteCiphertext`）。
- `putManifest`：If-Match 收到 412 且为坚果云时，走 `_retryNutstorePut` 验证降级：
  重新 GET 与基线逐字节比较——一致（假冲突）→ 无条件 PUT 覆盖（远端与本地基线
  相同，覆盖不丢数据）；不一致或重新 GET 404（真冲突）→ 维持原 ConflictException
  交回引擎重拉合并。409 与 If-None-Match 首次上传路径（实测可用）不降级。
- 残余并发窗口为一次 GET 往返（假冲突验证与降级 PUT 之间），退化为"最后写入胜"，
  由引擎下轮 GET-merge-PUT 兜底，与不返回 ETag 的服务器同级风险。

实测验证（Windows 应用日志）：三轮同步全部成功，每次出现
"[WebDAV] 坚果云兼容: If-Match 412 但远端未变化（假冲突），降级为无条件 PUT"，
manifest version 2→3→4 正常递增，GC 与隔离区结算正常。
