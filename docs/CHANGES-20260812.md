## 调试面板把索引当表查询修复：no such table: idx_notes_*（2026-08-12 19:28 GMT+8）

### 现象
- 日志反复刷屏（每次打开调试面板 DB 页出现 3 条）：
  `E/SQLiteLog: (1) no such table: idx_notes_uuid in "SELECT * FROM "idx_notes_uuid" LIMIT ?"`（idx_notes_deleted / idx_notes_synced 同理）。

### 根因（非数据丢失：safe_notes / sync_meta 表及三个索引都建得好好的）
- `idx_notes_uuid` 等三个对象是 `safe_notes` 表上的**索引（INDEX）**，SQLite 不允许 `SELECT * FROM <索引>`（报 no such table）。
- `NotesDatabase.inspectMetadata()` 从 `sqlite_master` 列出 `type IN ('table','view','index','trigger')` 全部对象；
  前端 `assets/web/dashboard.html` 的 `loadDb()` 对**每个**对象无条件调用 `loadTableData(t.name)`，
  于是索引名被当成表名请求 `/api/db?table=idx_notes_uuid`。
- 后端 `_serveDbInspect` 透传 table 参数给 `queryTableRows()`，后者只做标识符白名单校验（索引名是合法标识符，通过），
  执行 `SELECT * FROM "idx_notes_uuid"` → SQLite 原生报 no such table，刷屏。

### 改动（两层防御）
- 前端根因 `assets/web/dashboard.html`：`loadDb()` 仅对 `type==='table'||type==='view'` 的对象创建数据区并加载行数据；
  索引/触发器卡片只显示名称与类型，不再发查询请求（杜绝刷屏）。
- 后端防御 `packages/core/lib/src/db/database_handler.dart` `queryTableRows()`：查询前先查 `sqlite_master` 校验对象类型，
  非 表/视图 抛语义化 `ArgumentError`（`xx 是 index 类型，不是表/视图`），对象不存在也报明确错误；
  即使外部/手工直接请求 `?table=idx_notes_uuid` 也返回友好错误而非 SQLite 原生报错。

### 验证
- `flutter analyze` No issues；`flutter build windows --debug` 成功；`flutter run -d windows` 冒烟启动到登录页无崩溃（DB version=4 打开正常，进程已随管道退出清理）。
- 注：本轮改动未 commit（等待用户确认）。

## 页面切换黑屏修复：移动端改用平台默认转场（2026-08-12 18:31 GMT+8）

### 背景
- 用户反馈：手机端点开笔记/进入设置等所有 pushNamed 页面切换瞬间短暂黑屏。
- 根因：commit `9ac2664` 引入的自定义 `FadeThroughRoute`（lib/routes/route_generator.dart）设 `opaque: false` + 交叉淡入淡出（旧页前 60% 淡出、新页后 60% 淡入），动画约 40%~60% 区间两层同时接近全透明；全路由均非 opaque → Overlay 底层无任何不透明背景，直接透出引擎视图黑色背景，每次切换黑闪约 80ms（返回同样发生）。
- 佐证：旧版 `PageTransition(leftToRight)` 默认 opaque:true（旧页垫底）不黑屏；官方 `FadeForwardsPageTransitionsBuilder`（Flutter 3.44 SDK page_transitions_theme.dart）在交叉淡出期间显式 `ColoredBox(color: surface)` 垫背景（注释原文 "avoids a black background between two pages"）→ 非框架 bug，属自研转场实现缺陷。

### 改动（lib/routes/route_generator.dart）
- 移动端（Android/iOS）`_buildRoute` 由 `FadeThroughRoute` 改为 `MaterialPageRoute`：走 Flutter 默认 `pageTransitionsTheme`（Android = FadeForwards/预测性返回手势，iOS = Cupertino 滑动 + 边缘返回），符合官方 M3 推荐 forward/backward 用平台默认、随平台更新自动演进。
- 删除不再使用的 `FadeThroughRoute` 类（-56 行）。
- 桌面端保留 `PageTransition(fade, 250ms)`（Windows Fluent 风格，无黑屏问题）。

### 验证
- `flutter analyze` No issues；`flutter build windows --debug` 成功；`flutter run -d windows` 冒烟启动到登录页无崩溃（已结束进程并清理残留 exe）。

## 日志 Web 服务器迁移 + Dashboard 化（2026-08-12）

将调试能力从内置面板迁移为「JSON API + 静态 HTML Dashboard」，可跨设备远程访问；并把 LogWebServer 从纯 Dart 的 core 包迁到 Flutter 的 lib 层（webserver 是 Flutter 功能，放 core 不合理）。

### 架构与文件迁移
- `packages/core/lib/src/logger/log_webserver.dart` → `lib/src/logger/log_webserver.dart`（包名 `safenotes`）；`packages/core/lib/core.dart` 移除对应 `export`。
- 删除 `dashboardProvider`/`diagnosticsProvider`/`debugProvider` 三处注入（含 `main.dart`、`sync_service.dart` 注入点）。迁入 lib 后直接调用 `SyncService.instance`、`NotesDatabase`、`rootBundle`，消除循环依赖与补偿层。
- 调用点补 import：`lib/main.dart`、`lib/views/home.dart`、`lib/views/settings/sync_diagnostics_page.dart`、`test/test_helpers.dart`。
- 新增取数支撑方法：
  - `NotesDatabase.inspectMetadata()` / `queryTableRows()` / `cachedNoteSummaries()` / `dbFilePath`
  - `SyncService.getDebugJson()` / `getMemorySnapshot()`（含缓存笔记摘要、keyring 元数据、journal 摘要的真实数据）/ `getJournalDump()`
  - `PreferencesStorage.dumpAll()`、`SyncActionInfo.toJson()`

### 后端 API（lib/src/logger/log_webserver.dart）
- 数据端点：`/api/status`、`/api/sync`、`/api/actions`、`/api/memory`、`/api/prefs`；
  `/api/db?table=&limit=` 返回该表前 N 行数据（blob 列显示 `<blob N B>`；notes 表的加密列 `title`/`description` 不返回）。
- 下载端点：`/api/download/{logs,diagnostics,db,sp,journal}`。
- 页面/流：`/panel`（从 `assets/web/dashboard.html` 读取，单一真源）、`/stream`（WebSocket 日志）、`/diagnostics`。
- 全端点加 CORS（`Access-Control-Allow-Origin: *` + `OPTIONS` 预检）。

### 前端 dashboard.html（assets/web，单一真源）
- 6 标签 Status / Sync / Actions / Logs / DB Inspector / Memory；顶栏 Refresh All + 两个英文下载按钮（Download Data: db+prefs；Download Logs: log+journal+diagnostics），用隐藏 iframe 触发多文件下载，避免弹窗拦截且不离开面板。
- Logs 追平 `/` 查看器：级别 chips、标签过滤、关键字、自动滚动、暂停/重连、按级别着色；`flex:1` 撑满整屏高度。
- DB Inspector 默认显示数据行（schema 折叠）；内存快照显示真实数据。
- 连接失败不清空已有数据，仅更新顶部状态点（Disconnected）；pane 为空时仅追加淡灰 `(offline)`。

### 调试面板清理
- `lib/views/settings/sync_diagnostics_page.dart` 删除临时 Tests Tab（KDF 基准）及未用 `cryptography` import；`TabController` 长度同步由 6 改为 5。
