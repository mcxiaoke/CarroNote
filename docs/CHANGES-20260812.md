# 2026-08-12 变更记录

## 修复 / 测试（集成测试沙箱适配，2026-08-12 11:37 GMT+8）
- **日志服务器开关（UI 集成测试）**：`packages/core/lib/src/logger/log_webserver.dart`
  新增静态开关 `LogWebServer.enableWebServer`（默认 true）；`test/test_helpers.dart`
  的 `initTestEnv()` 中设为 `false`。原因：HttpServer 的 idle-timeout 会创建周期性
  Timer，在 flutter test 的 FakeAsync 环境下永远 pending，导致测试结束报
  "A Timer is still pending"。日志服务器正确性由 core 包独立测试覆盖，集成测试只测 UI。
- **测试加密替身 MAC 校验**：`test/test_helpers.dart` 的 `_TestAesGcm.decrypt` 增加
  MAC 校验（HMAC-SHA256(key, cipherText) 前 16 字节与 SecretBox.mac 常数时间比较），
  错误主密钥复算_MAC 不匹配 → 抛 `SecretBoxAuthenticationError` → 最终 `WrongPasswordException`，
  修复了 auth_flow_test「错误密码」分支因 XOR 对称可逆而永远登录成功、无法触达的问题。
- **`test/auth_flow_test.dart`**：将 "Safe Notes" 断言放宽为 `findsAtLeastNWidgets(1)`
  （≥600px 视口下 AppBar 与 HomeSidebar 都会渲染该文本，原 `findsOneWidget` 误判）；
  移除排查用的临时 `pump(const Duration(seconds: 8))`。3 个测试通过。
- **`test/export_backup_dialog_test.dart`**：翻译加载由 `dart:io File.readAsString` 改为
  `rootBundle.loadString`（本机沙箱里 dart:io 文件 I/O 会永久挂起、冻结事件循环）；
  删除未使用的 `dart:io` 导入。3 个测试通过。
- **`test/sync/sync_config_test.dart`**：localFs 连通性测试改用项目本地 `temp/` 目录
  （而非 `Directory.systemTemp`，沙箱阻断系统临时目录创建，致 `createTemp` 永久挂起）。
  14 个测试通过。
- **清理**：删除排查期间产生的临时诊断文件 `test/_diag_*.dart`、`test/_probe_*.dart`、
  `test/auth_diag_test.dart`（共 16 个），仅保留真实测试与共享 harness `test_helpers.dart`。
- **沙箱环境限制（非代码缺陷，需在普通开发环境运行）**：`test/sync/change_password_multi_client_test.dart`、
  `test/generate_real_db_test.dart`、`scripts/cli-e2e-test.ps1` 依赖真实 `Argon2id`
  （后台 isolate 派生 MK）与/或系统临时目录，在本机 `flutter test` 沙箱下会挂起；
  cli-e2e 还需先编译 AOT 二进制（`build/cli/bundle/bin/safenotes_cli.exe`）否则回退
  `dart run`（每调用一次跑 build hooks，且同样因真实加密挂起）。core 包自身测试同理，
  其正确性由非沙箱环境保障（用户已确认 core 包已有大量测试）。
