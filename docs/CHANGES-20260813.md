## 暗色模式对比度修复：Shad 侧改走 M3 自适应色板（2026-08-13 11:05 GMT+8）

### 问题
暗黑模式下（如默认 0-0 深海蓝）几乎所有按钮「深色底 + 黑色字」看不清，
笔记颜色页选中项文字同样看不清。

### 根因
`ShadThemes.build` 的 `copyWith` 只覆盖了 `primary: seed`，未同步
`primaryForeground`。而 `ShadSlateColorScheme.dark()` 的 primaryForeground
默认是深色（#0f172a）→ 深 seed 底色 + 深文字 = 不可读。浅色模式恰好默认
primaryForeground 是白字，所以未暴露。**这是 Shad 对接层破坏了主题色自动对比
机制**，而非业务代码没用主题色 —— FCS（Material）侧一直正常（M3 自动推导
onPrimary，暗色下 primary 自动提亮、文字自动变深，对比度 7.75:1）。

### 改动（lib/models/shad_theme.dart 重写）
- 品牌相关色一律改用 M3 `ColorScheme.fromSeed(seedColor: seed, brightness:)`
  生成的色板映射，不再直接塞裸 seed：
  - `primary/primaryForeground` ← m3.primary / m3.onPrimary（核心修复）
  - `secondary/secondaryForeground` ← m3.secondary / m3.onSecondary
  - `accent/accentForeground` ← m3.primaryContainer / onPrimaryContainer
  - `destructive/destructiveForeground` ← m3.error / m3.onError
  - `ring` ← m3.primary；`selection` ← primary 20% 透明度
- 中性基底（background/foreground/card/border 等）仍沿用 Slate，页面观感稳定。

### 效果（实测对比度）
| 模式 | primary | 文字 | 对比度 |
|---|---|---|---|
| 浅色 | #3E5F90（深蓝） | 白 | ~7:1 ✓ |
| 暗色 | #A7C8FF（亮蓝） | #04305F（深蓝） | 7.75:1 ✓ |

暗色模式按钮变为「亮底深字」——这是 M3 标准暗色行为（primary 自动提亮保证
可读），任何 seed（含极深色）都自动自适应，无需手调任何颜色。
笔记颜色页/主题色页选中项文字用 colorScheme.primary，随修复自动变亮可读。

  13 用例全部通过。

## 实时主题颜色切换：JSON 分组色库 + FCS/Shad 双轨动态换肤（2026-08-13 10:40 GMT+8）

### 需求
Safenotes 原仅支持明暗模式切换，品牌色（seed）硬编码为 Nord 蓝，用户无法换肤。
目标：运行中实时更换主题颜色（品牌色），无需重启、立即生效、持久化保存。
用户提供 `temp/theme_colors.json`（6 组 × 16 色 = 96 色，含中英文名），指定
**冷调专业为第一组、其第一个颜色「深海蓝」#0F3460 为默认**；中文 locale 显示中文名、
其他语言显示英文名；选择器 UI 统一使用 shadcn_ui。

### 1. 数据层：JSON 色库 + 生成脚本（新增）
- `lib/data/theme_colors.json`：6 组 × 16 色（冷调专业/经典通用/柔和马卡龙/复古莫兰迪/
  高饱和活力/自然大地），每组 `name`+`nameEn`，每色 `name`+`nameEn`+`color`（#RRGGBB 恒不透明）。
  色值经脚本校验：无透明、无重复（原「桃红色」0xFF6B9D 6 位透明已修正为 0xFFFF6B9D）。
- `scripts/generate_theme_seeds.py`：读 JSON → 生成 `lib/models/theme_seeds.g.dart`
  （ColorSeedItem / ColorSeedGroup / AppThemeSeeds，含 clamp 防越界取色方法与双语显示名方法）。
  与项目 `generate_build_info.py` 同风格：仅标准库、内容未变化不写文件。
- 运行时不用 rootBundle 异步加载（ThemeProvider 同步构造需立即取 seed），JSON 仅作数据源。

### 2. 模型层：ThemeProvider 二维索引 + 主题参数化（修改）
- `lib/models/app_theme.dart`：
  - `ThemeProvider` 增加 `groupIndex` / `colorIndex` / `seedColor`（getter）与
    `setThemeColor(g, i)`（更新索引 → 持久化 → `notifyListeners()` 全局重建）。
  - `AppThemes` 由无参 `lightTheme/darkTheme` getter 改为 `build(seed, brightness)` 方法；
    品牌 seed 常量 `_brandSeed` 移除，seed 由 Provider 动态提供。
- `lib/models/shad_theme.dart`：`ShadThemes.build(seed, brightness)`，基于
  ShadSlateColorScheme.light/dark + copyWith 覆盖 primary/ring/selection（双轨同步换色）。
- `lib/app.dart`：`themeProvider.seedColor` → `ShadThemes.build` / `AppThemes.light/dark(seed)`。

### 3. 持久化：两个 int 索引（修改）
- `lib/data/preference_and_config.dart`：新增 `themeGroupIndex` / `themeColorIndex`
  get/set（key: themeGroupIndex / themeColorIndex，默认 0），配置快照日志补充两个字段。
  存 index 不存色值：日后调整 hex 老用户自动生效；读取方 clamp 防越界。

### 4. UI：shadcn 分组色库选择器（新增 + 修改）
- `lib/views/settings/theme_color_setting.dart`（新增）：`ThemeColorPicker` 页面，
  ShadTabs<int> 分组切换 + 色块网格（桌面 4 列/移动 3 列圆形色块 + 选中边框勾）+ 顶部常驻大预览，
  色名按 `context.locale.languageCode == 'zh'` 双语显示；点击色块调 `ThemeProvider.setThemeColor`。
- `lib/views/settings/theme_setting.dart`：弹层「Dark mode」开关组下新增
  「Theme color」导航行（右侧显示当前色名），跳转 `/themeColorSettings`。
- `lib/routes/route_generator.dart`：注册 `/themeColorSettings` → ThemeColorPicker。
- `assets/translations/en-US.json` / `zh-CN.json`：补充 `Theme color`（主题颜色）、
  `Selected`（已选择）翻译 key。

### 5. 测试
