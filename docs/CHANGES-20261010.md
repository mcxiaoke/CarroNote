# 2026-10-10 变更记录

## 2026-10-10 22:12:15 — feat(backup/desktop): 桌面端默认备份目录增加 CarroNote 子目录并自动创建

### 需求与背景

- **桌面端默认备份散落**：此前桌面端（Windows / macOS / Linux）在 `FileHandler.defaultBackupDirectory()` 中直接返回应用文档根目录（`Documents`），未如移动端（`Download/CarroNote`）创建专用子文件夹，导致自动备份与默认导出文件直接散落在用户的系统「文档」根目录中，排查与管理不便。

### 核心改动

1. **新增桌面备份子目录常量与属性**：
   - `lib/data/preference_and_config.dart`：在 `SafeNotesConfig` 中增加 `_desktopBackupSubdirectory = 'CarroNote'` 常量与公共 getter `desktopBackupSubdirectory`。
2. **优化桌面端默认备份落盘路径**：
   - `lib/models/file_handler.dart`：`defaultBackupDirectory()` 在 `isDesktopPlatform` 时拼接 `Documents/CarroNote`，并自动确保目录已创建（`create(recursive: true)`）；失败时安全回退至文档根目录。
3. **注释与设计文档同步**：
   - `lib/utils/scheduled_task.dart` 与 `lib/data/preference_and_config.dart`：同步相关注释描述（桌面端默认=Documents/CarroNote）。
   - `docs/platform-differentiation.md`：更新桌面端备份路径说明。
4. **单测覆盖**：
   - `test/data/preference_and_config_test.dart`：增加 `SafeNotesConfig.desktopBackupSubdirectory` 常量断言。
   - `test/models/file_handler_test.dart`：新增桌面平台下 `FileHandler.defaultBackupDirectory()` 子目录自动创建与路径匹配单元测试。
