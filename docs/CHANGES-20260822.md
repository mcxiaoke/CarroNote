## 13:50 修复非 Markdown 预览模式行高偏大（编辑↔预览不一致）

**文件**: `lib/utils/editor_text.dart`, `test/check_leading_test.dart`（新增）

- **问题**: 非 Markdown 预览模式下，预览态行高/间距明显大于编辑态，字号越大越明显。
- **根因**: 预览态 `SelectableText` 直接使用 `TextStyle.leadingDistribution`；该样式与 shadcn `textTheme.muted`（`height:20/14≈1.428`, `leadingDistribution: TextLeadingDistribution.even`）merge 后继承了 `even`——行高余量均分到行上下两侧，视觉上间距偏大。而编辑态 `EditableText` 会自动生成默认 `proportional` 的 `StrutStyle` 覆盖该值（余量全放行底），故编辑态正常。
- **修复**: `_style()` 在 `base.copyWith(...)` 中显式设置 `leadingDistribution: TextLeadingDistribution.proportional`，让预览态与编辑态行为一致。Markdown 预览同样经此链构造，一并修复。
- **测试** (`check_leading_test.dart`): 新增断言式测试——验证 shad muted 为 `even`，`EditorText.body()/title()` 经 merge 后 `leadingDistribution == proportional`，`bodyOf/titleOf` pending 预览版本同样为 `proportional`。

## 10:27 修复 findIncompleteOperations 对无 opId 条目的误报

**文件**: `packages/core/lib/src/sync/journal.dart`, `packages/core/test/sync/journal_test.dart`

- **问题**: 每次启动报告几十条 `sync.round/start` 未完成（实测 48 条），但同步实际都正常完成了。根因：`findIncompleteOperations` 只按 opId 配对 start↔done/failed，而 `sync.round` 条目从不携带 opId，done 永远无法闭合对应 start，导致每轮正常同步的 start 都被误报为悬挂，随启动次数不断累积。
- **修复**: 无 opId 的条目改为「同类型顺序配对」——start 之后遇到的第一条同类 done/failed 即视为其配对（sync.round 全程串行执行，同一时刻至多一轮在途，该规则是精确的）；带 opId 的条目仍按 opId 精确配对。真正中断的轮次（start 后无 done）依然会被正确报告。
- **测试**: 新增 2 个用例：两轮完整无 opId 同步不报告；第二轮中断仍报告。`dart test packages/core/test` 全部 350 个通过；`flutter analyze` 仅剩存量的 `test/pin_keyboard_test.dart` 4 个无关错误。

## 09:29 修复日志 Web 服务器下载端点中文内容编码错误

**文件**: `lib/src/logger/log_webserver.dart`, `test/logger/log_webserver_test.dart`（新增）

- **问题**: `GET /api/download/sp` 返回 500，报 `Invalid argument (string): Contains invalid characters.`。原因：`_sendAttachment` 用 `ContentType.parse('application/json')` 设置响应类型，无 charset 时 Dart `HttpResponse.write()` 默认按 Latin1 编码输出，SP 快照含中文标签（如 `"个人"`）即抛异常。
- **修复**: `_sendAttachment` 中当解析出的 ContentType 无 charset 时显式补 `charset: 'utf-8'`。
- **测试**: 新增 `test/logger/log_webserver_test.dart` 回归测试——mock SharedPreferences 含中文值，经原始 socket 请求 `/api/download/sp`，断言 200、UTF-8 charset 且 JSON 可正确解码中文。（用原始 socket 是因为 flutter test 环境会劫持 HttpClient）
- **验证**: `flutter analyze`（该文件无问题）、新增单测通过；core 包 348 项测试全部通过。
