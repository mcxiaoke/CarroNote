## 2026-08-31 评审遗留问题第一批修复（H-1 / H-2 / H-6 / M-5 / M-6）

> 依据 `docs/review-open-issues-20260831.md` 优先批次「小改动、高收益」逐项实施。未 commit。

* **H-1（WebDAV journal 路径遍历）**：`webdav_backend.dart` `listJournalObjects` 现仅 `endsWith('.json')` 无白名单，恶意/共享 WebDAV 返回 `%2E%2E%2F...` 可逃逸目录并发带认证头 GET。修复为与 SafeServer 对齐：校验 `^[A-Za-z0-9._-]+$` 且不含 `..`。

* **H-2（`getPendingReuploadUuids`** **静默空）**：`database_handler.dart` 该方法此前 JSON 损坏时 `return {}`（旧 key blob 永久残留远端）且 `as String` 抛 TypeError（Error）逃逸。现改为与 `_parseUuidList` 同一策略——损坏/非数组/元素非法一律 `throw FormatException` 中止同步链路。同步更新 `database_migration_rollback_test.dart` 对应用例（损坏→抛异常）。

* **H-6（迁移守卫 5 处残留）**：为 `hardDeleteAllDeleted` / `markAllForBlobReupload` / `mergeRemoteNoteMetas` / `markNoteMetasSynced` / `purgeReportedNoteMetaTombstones` 补 `_checkNotMigrating()`。核验 `reEncryptAllNotesAtomically` 内用 txn 直写 `blobReuploadPending`，不走 `markAllForBlobReupload`（该函数现仅注释遗留、无调用方），加守卫不破坏迁移；其余在同步 meta 路径调用，与迁移窗口无交叠。

* **M-5（Ctrl+N 竞态崩溃）**：`add_edit_note.dart` `_handleNewShortcut` 由 `unawaited(_performAutoSave)` 后立即导航，改为 `await _performAutoSave(keepEditing:true)` 完成后再导航（防新页 `setState(null,'','')` 覆盖静态 `original` 触发空值断言崩溃并静默丢改动）。

* **M-6（滚动动画崩溃）**：`set_passphrase.dart` / `change_passphrase.dart` 的 `scrollToBottomIfOnScreenKeyboard` 补 `try{...}catch(_){}`（与 `login.dart` 对齐），防 build 首帧 `_scrollController` 未 attach 抛 `StateError`。
