## 2026-08-31 评审第四批修复（H-4：远端切 key 前本地可解性校验）

> 依据 `docs/review-open-issues-20260831.md` H-4（原 P1-1/C1，数据安全最高优先）。未 commit。

- **根因**：`unlockFromRemoteManifest`（登录本地账本失效时改走远端验证）直接 `persist` 远端 keyring 并
  `setDataKey(远端 dataKey)`，不做重加密也不做校验。若本地 notes 用另一把 key 加密（账本被旧备份回滚 /
  只恢复 notes 表 / 跨 vault 混数据），静默切 key 会把本可挽救的本地数据变成永久不可解。
- **修复**：
  - 新增 `NotesDatabase.verifyDataKey(Uint8List candidateKey)`：用候选 key（不改内部 `_dataKey`）抽样
    试解前 5 行 title 密文——空库/任一成功返回 true（正常多设备/新设备放行），抽样全失败返回 false。
  - `Keyring.unlockFromRemoteManifest` 在 `persist` 前调 `verifyDataKey`，false 时抛新增
    `LocalVaultKeyMismatchException`（`sync_error.dart`）拒绝覆盖。
  - `login.dart` 捕获该异常返回 `RemoteVerifyResult.localVaultMismatch`，提示"本地保险库无法用此密码
    解密，请先从备份恢复再登录"（不扣尝试次数、不走 wrongPassword）；补充 `zh-CN.json` / `en-US.json` 文案。
- **回归测试**：`keyring_test.dart` 新增 2 例——`verifyDataKey` 三分支（空/匹配/不匹配）、
  `unlockFromRemoteManifest` 本地 key 与远端不一致时抛 `LocalVaultKeyMismatchException`。
- **验证**：`dart format` 5 文件；`dart analyze`（sync_error/database_handler/keyring/login/keyring_test）
  No issues；`dart test packages/core/test/sync/keyring_test.dart` 34 通过（+2）；`flutter analyze lib assets`
  No issues；`flutter test` 246 通过。
