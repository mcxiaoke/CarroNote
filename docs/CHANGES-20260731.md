# 变更日志

## [2026-07-31 13:10:38] - SafeServer v2.2 通用资源层

### 协议升级（docs/server-api-spec.md → v2.2）

- **新增通用资源层 `/api/v2/resources/<path>`**（§5.10）：用纯 REST/JSON 表达等价于 WebDAV `GET`/`PUT`/`DELETE`/`MOVE`/`MKCOL`/`COPY`/`PROPFIND` 的语义。
  - `GET` / `PUT` / `DELETE` 复用原生 HTTP 方法。
  - `move` / `copy` / `mkdir` / `propfind` / `stats` 通过 `POST /api/v2/resources/<path>` + JSON body `{op,...}` 触发。
  - 兼容任意 HTTP client（不使用 WebDAV 专有方法）。
- **消除"能力倒置"**：`safeServer` 软删除孤儿 blob 现可走 `move` 到 `blobs-orphan/`，与 `localFs`（`rename`）/`webdav`（`COPY`+`DELETE`）能力对齐，省去旧方案 `GET`+`PUT`+`DELETE` 三段往返与 `0rphan-` 前缀污染。
- **`manifest`/`blob` 端点保留为资源层便利接口**（§5.2–§5.9 语义不变），旧 v2.1 客户端继续兼容；旧服务端对资源层返回 405 时客户端静默降级。
- **新增路径安全红线 `ValidateVaultPath`**（§9.7）：禁止空路径/绝对路径/`..` 逃逸/NUL/反斜杠，规范化后校验最终路径停留在 vault 根内。
- 错误码补充：400（路径非法）、405（`mkdir` 目标已存在）、409（`move`/`copy` 冲突 / `mkdir` 父目录缺失）；`ResourceEntry` 字段定义（§5.10.4）。
- 版本历史追加 v2.2（§15）。

### 参考实现升级（Go + Node.js 同步）

- **Go**（`server/go/internal/storage/storage.go`、`fs.go`、`server/handlers.go`、`server/server.go`）：

  - `fs.go`：`fsVault` 新增 `resolveResourcePath` 及资源层 7 方法实现；blob 的 Get/Put/Delete 委托到 `blobs/<hash>` 资源；`manifest` 路径特化回复用互斥锁实现。
  - `handlers.go`：新增 `handleGetResource`/`handlePutResource`/`handleDeleteResource`/`handleResourceOp`（move/mkdir/copy/propfind/stats）+ `mapResourceErr` 错误映射。
  - `server.go`：新增 `/api/v2/resources/` 路由分支（GET/PUT/DELETE/POST），启动日志改为 `SafeServer v2.2 (Go) starting`。
- **Node.js**（`server/nodejs/src/storage/storage.js`、`fs.js`、`src/handlers.js`、`server.js`）：
  - `storage.js`：新增 `ErrInvalidPath`/`ErrExists`/`ErrConflict`、`ResourceEntry` 类、`validateVaultPath`、`Vault` 基类 7 方法桩。
  - `fs.js`：`FsVault` 新增 `resolveResourcePath` 及资源层 7 方法；blob 委托到资源层；`manifest` 特化复用。
  - `handlers.js`：新增 `getResource`/`putResource`/`deleteResource`/`resourceOp` 及错误映射。
  - `server.js`：新增 `/api/v2/resources/` 路由分支，启动日志改为 `SafeServer v2.2 (Node.js) starting`。
- **实现文档**（`docs/server-implementation.md` → v2.2）：同步更新接口定义、目录结构、路由、存储布局、路径穿越防护、测试项、日志示例。

### 设计约束遵循

- 未超出 `localFs`/`webdav` 后端的能力上限（仅对齐，不超出），符合"三 backend 兼容、server 能力不超过 webdav/fs"的要求。
- 零知识不变：服务端不解析 blob 内容，仅操作路径与元数据。
- 未修改客户端 `safe_server_backend.dart`、未修改任何依赖文件（`pubspec.yaml`/`package.json` 未改动）。
