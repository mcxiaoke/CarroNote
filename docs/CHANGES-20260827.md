## 2026-08-27 11:40 中优先级 5 项修复（RELEASE-REVIEW 中优先）

对应 docs/RELEASE-REVIEW-20260826.md 中优先 7 项中的 5 项（4 与 7 暂缓）：

### 1. update 系列 rows==0 仍写缓存产生幻影笔记 `database_handler.dart:1270-1321`
- `updateNote`（按 id）与 `updateNoteByUuid`（按 uuid）此前无论 `db.update` 返回 rows 是否为 0 都调 `_upsertCacheEntry(note)`，DB 中不存在的行会凭空新增缓存条目，形成幻影笔记。
- 修复：两处 `db.update` 后加 `if (rows > 0)` 守卫，rows==0 时不写缓存，直接 return 0。DB 与缓存强一致。

### 2. 导入备份批内 uuid 重复导致整体回滚 `database_handler.dart:983-1030`
- `storeNotesInTransaction` 已有库中去重（`_existingUuids`），但未过滤批内重复 uuid，批内重复触发 `safe_notes.uuid` UNIQUE 整体回滚。
- 修复：先按 uuid 首现去重（`seenBatch` 去重，仅保留首个），再查库去重；日志区分批内/库中跳过数。复用现成 chunk 逻辑避免 IN 上限。

### 3. markSynced 系列 IN 子句超 SQLite 变量上限 `database_handler.dart:2165-2226`
- `markAllSyncedExcept` 与 `markSyncedForUuids` 曾用单条 `IN (?,?,?,?,...,?)` 拼全部 uuid，超过 SQLITE_MAX_VARIABLE_NUMBER（999）抛错。
- 修复：
  - `markSyncedForUuids`：按 400 分片，多 chunk 在事务内批量 `UPDATE ... IN (?)`，单 chunk ≤400。
  - `markAllSyncedExcept`：NOT IN 不能简单多语句分片（会把应排除的行在另一片中误标）。≤900 时单条 NOT IN；>900 时走补集路径：`SELECT uuid` 求全量补集，再复用白名单分片 IN 标记（事务内）。语义等价且不超限。

### 5. 回收站恢复成功无提示、"清空成功"用 error 样式 `deleted_notes.dart:152-228`
- `_restoreNote` 成功分支的 `showSnackBarMessage('Restored: ...')` 被注释，无成功提示。
- `_permanentDelete` 与 `_clearAll` 成功用 `showErrorToast`（destructive 红色），误导为失败。
- 修复：恢复时展示 `showSnackBarMessage('Restored: "{title}"')`；永久删除与清空成功改用 `showSnackBarMessage`（信息样式，3s）；error 样式仅保留给失败分支。

### 6. 版本历史/回收站页异常时永久转圈；宽屏无限宽约束无 Scrollbar
- 回收站 `_refresh` 已在 M1 修复；版本历史 ` _loadData` 仅 `readVersions` 有 try/catch，`getNoteMeta` 异常会使 `_versions` 保持 null 永久转圈；`_updateDiff` 的 `computeNoteDiffAsync` 异常未复位 `_isLoading`。
- 宽屏：两页面内容无 `maxWidth` 与 `Scrollbar`，宽屏拉伸过宽且无可见滚动条。
- 修复：
  - `version_history_page.dart: _loadData` 整段 try/catch（含 meta），异常降级为空列表 + toast，必置 `_versions`；`_updateDiff` 包 try/catch/finally，异常复位 `_isLoading` 并 toast。
  - `deleted_notes.dart`：`_scrollController` + `Scrollbar(thumbVisibility: isDesktopPlatform)` + `ListView(controller: ...)`；`Scaffold.body` 外包 `Center > ConstrainedBox(maxWidth:800) > SizedBox.expand` 限宽居中。
  - `version_history_page.dart`：双 `ScrollController`（full/diff）+ 双 `Scrollbar`；`Scaffold.body` 与 `bottomNavigationBar` 同包 `Center > ConstrainedBox(maxWidth:800) > SizedBox.expand`，桌面可视滚动条、移动端保持默认。
