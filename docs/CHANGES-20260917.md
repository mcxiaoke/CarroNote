## 2026-09-17 登录页本地验证脱离网络依赖 & 回退桌面日志目录与 PIN 失败限制

* **目标**：彻底纠正本地密码验证依赖远端网络导致的误报问题；回退桌面日志路径改动（保持写入 AppData 预期位置）；回退本地 PIN 失败限制（消除卡死隐患）。
* **修改内容**：
  1. **[本地优先纠正] 登录页本地密码验证完全闭环** (`lib/views/authentication/login.dart`)：
     - 本地已初始化场景（`isInitialized == true`）下，密码解锁本地 Keyring 失败时直接调用 `_onLoginFailure()` 提示“密码错误”，**严禁触发远端网络验证**。
     - 仅在本地库尚未初始化（新设备冷安装通过远端同步接入已有 Vault）场景下，才允许尝试远端 manifest 验证。彻底根除了自建/局域网同步服务器离线时，本地输入错误密码却被误报为“无法验证密码，网络不可用”的违和体验。
  2. **[体验预期对齐] 保持桌面端日志写入 AppData** (`packages/core/lib/src/logger/app_logger.dart`)：
     - 撤销对 exe 同级目录写日志的改动，恢复原有由 App 层注入的 `%APPDATA%` 数据目录，符合非 portable 版安装规范与用户检索习惯。
  3. **[稳定性保障] 回退本地 PIN 失败限制**：
     - 回退此前在 PIN 输入上叠加的失败锁定逻辑，防止本地 PIN 校验因防暴力重试过度防御引发 UI 状态机卡死与灰屏。
* **验证**：
  - `flutter analyze` 静态分析全绿（No issues found!）；
  - `dart test packages\core\test` 443 项测试全部通过；
  - `flutter test` 认证与界面测试全部通过；
  - `flutter build windows --debug` 编译顺利生成 `CarroNote.exe`。

## 2026-09-17 修复 SessionStateStream 类型转换崩溃并健全全局异常落盘与崩溃兜底

* **目标**：修复 `SessionTimeoutManager` 因误传 `StreamController` 导致类型不匹配崩溃的问题；解决 Release 模式下异常被吞、日志无输出、静默灰屏卡死的问题。
* **修改内容**：
  1. **[Bug 修复] SessionStateStream 传参修正** (`lib/main.dart`)：
     - `SessionTimeoutManager` 的 `sessionStateStream` 改传 `sessionStateStream.stream`，消除 `type 'AsyncStreamController<SessionState>' is not a subtype of type 'Stream<SessionState>?'` 运行时崩溃。
  2. **[异常治理] 全局错误钩子立即 Flush 落盘** (`lib/main.dart`、`packages/core/lib/src/logger/app_logger.dart`)：
     - `FlutterError.onError`、`PlatformDispatcher.instance.onError`、`runZonedGuarded` 统一在记录异常后立即触发 `AppLogFile.flush()`，防范应用退出导致内存缓冲丢失。
     - 底层 `_HybridOutput` 与 `AppLogFile.writeLine` 针对 `error` 和 `fatal` 级别自动执行紧急 flush。
  3. **[日志体验] Release 默认日志级别与桌面端路径优化** (`packages/core/lib/src/logger/app_logger.dart`)：
     - Release 模式默认日志级别提升至 `Level.info`，保证启动生命周期与关键操作上下文被完整记录。
     - 桌面端（Windows/macOS/Linux）日志路径真正优先落入 exe 同级 `logs/` 目录，便于直观排查。
  4. **[体验防线] Release 模式自定义 ErrorWidget 崩溃兜底页** (`lib/main.dart`)：
     - 自定义 `ErrorWidget.builder` 替代 Flutter 原生静默灰屏，展示错误摘要与日志落盘路径，杜绝无提示卡死。
* **验证**：
  - `dart format` 格式化通过；
  - `flutter analyze` 静态分析无报错；
  - `dart test packages/core/test/logger/app_logger_test.dart` 核心日志测试通过；
  - `flutter test test/export_backup_dialog_test.dart` 视图测试通过；
  - `flutter build windows --debug` 编译通过。
