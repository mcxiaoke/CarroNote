# SafeNotes 变更日志 2026-08-10

> 本轮按 `docs/flutter-code-review-20260810.md` 逐条修复代码评审问题（高 2-7、中 9-18 全部完成）。

## 安全与数据正确性（高）

- **高 2 桌面端"假备份"**（`lib/utils/scheduled_task.dart`）：`unitBackupAttempt()` 桌面端不再 `return true`，改为返回 `false` 并写 `lastBackupError`，让改密码前置 `forceBackup()` 与自动备份链路如实感知失败。
- **高 3 登录锁定倒计时可重置**（`lib/views/authentication/login.dart`）：`_buildTimeOut()` 只读 stream 不再启动 Timer/清输入框；新增 `_startLockoutTimer()` 仅在锁定瞬间启动一次倒计时。
- **高 4 锁定 off-by-one + 双份实现**：`_passphraseValidator` 只做非空校验；锁定统一收口到 `_onLoginFailure → _startLockoutTimer`。
- **高 5 drawer/navrail 外链错指 GitHub**（`lib/widgets/drawer.dart`、`lib/widgets/home_navigation_rail.dart`）：Rate Us/FAQs/Help 分别接 `playStoreUrl`/`faqsUrl`/`githubUrl`（含本地化文案）。
- **高 6 sync() 互斥锁 check-then-act 竞态**（`lib/sync/sync_service.dart`）：`sync()` 与 `repairRemote()` 互斥锁移入口第一行（任何 await 之前）抢锁，消除两个并发 sync 同时通过检查的窗口。
- **高 7 远端验证路径资源泄漏 + 误分类**（`login.dart`）：`backend.close()` 移入 `finally`；远端无 manifest（空 ciphertext）改判 `RemoteVerifyResult.unreachable`，不再误扣尝试次数。
- **高 8 口令驻留内存**：未处理（需大规模改造，暂搁置）。

## 可靠性与逻辑（中）

- **中 9 信封过短抛未包装异常**（`packages/core/lib/src/crypto/crypto.dart`）：`_aesGcmDecrypt` 在任何 `sublist`/`SecretBox` 构造前校验 `envelope.length >= 28`，过短抛 `SyncDecryptionException` 而非裸 `RangeError`。
- **中 10 导入无事务无上限**（`lib/models/file_handler.dart`）：读文件改 `readAsString` 异步 + 256MB 大小上限；新增 `NotesDatabase.storeNotesInTransaction` 单事务批量写入，任一条失败整体回滚。
- **中 11 重试 50 次无退避**（`scheduled_task.dart`）：`backup()`/`forceBackup()` 加 30s 总超时预算 + 指数退避（200ms 基础、5s 封顶）。
- **中 12 dispose 后写入已关闭 controller**（`sync_service.dart`）：`_updateState` 加 `_stateController.isClosed` 守卫；`autoSync` 的 `.then` 补 `onError:` 兜底 `Error`。
- **中 13 编辑器全局静态态 + 双写竞态**（`lib/models/editor_state.dart`、`lib/views/add_edit_note.dart`）：`addOrUpdateNote` 加 `_isSaving` 防重入（try/finally）；`isNoteNewOrContentChanged` 改为对 `widget.note` 逐字段比较（清空标题也算改动）。
- **中 14 set_passphrase 时序**（`set_passphrase.dart`）：成功 snack + `sessionStream.add(startListening)` 移到 `_initKeyring` 成功及 `Session.onPasswordSet` 之后。
- **中 15 build 副作用**（`lib/main.dart`、`lib/views/change_passphrase.dart`）：main 会话订阅仅在 focus/inactivity 配置变化时重建（不再每次 build 重置超时基准）+ `navigatorKey.currentContext!` 改判空；change_passphrase 仅键盘从无到有时触发滚动动画。
- **中 16 核心包小问题**：
  - `sync()` 文档修正：注明 `BackendUnavailableException` 直接抛出，由上层兜底；
  - `_openBlobEnvelope` 删除 `uuid` 死参数（同步更新 3 处调用点）；
  - `_gcOrphanBlobs` 整体 GC 外层 `on Exception` → `on Object`；
  - `keyring._sameKey`（非常数时间）与 `sync_engine._bytesEqual`（常数时间）统一收敛为 `SyncCrypto.bytesEqual`（常数时间）；
  - `getManifestVersion` 的 `int.parse` 改 `int.tryParse` + 日志降级为 0；
  - `_parseUuidList` 解析失败不再静默返回空列表，改抛 `FormatException` 显式中止（防 purged 列表损坏导致硬删除笔记从远端复活）。
- **中 17 诊断端点泄露基础设施信息**（`sync_service.dart`）：诊断快照 URL 经 `_redactUrl`（掩 userinfo/query）、用户名经 `_maskUsername` 脱敏。
- **中 18 配置双默认值/双数据源**（`lib/data/preference_and_config.dart`、`lib/views/settings/settings.dart`、`inactivity_setting.dart`）：缺省统一为索引 3（180s）；抽取 `kInactivityTimeoutChoicesSeconds` 唯一数据源；settings onToggle 使用入参而非取反；inactivity_setting 列表从常量派生并保留 Default 标记。
